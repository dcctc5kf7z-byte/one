## Hermes 文本透视诊断界面设计（v2 融合版）

### 完成的工作
1. **设计风格分析**：拆解 Hemingway Editor 和 Ollama 网站的视觉架构
2. **融合方案制定**：结合两者优势，解决旧版"狭窄紧绷"问题
3. **全新界面构建**：在 Ardot 中实现 Hermes v2 设计

### 核心改进
- **布局重构**：从左右分栏挤压 → 单栏居中流式布局（Hemingway 式宽松感）
- **空间优化**：主内容区 padding 80px，gap 48px，大量留白
- **输入框升级**：320px 高大面积编辑框 + 16px 圆角 + 柔和阴影
- **视觉层次**：标题(32px) → 描述(17px) → 输入框 → 信号条 → 诊断结果（渐进式展示）
- **Ollama 元素**：蓝色边框强调卡片、12-16px 圆角、柔和投影
