## 一、测试：不用 Claude 网页版也能测

你有三条路，按推荐顺序：

### 方案 A：直接在 Claude Code 里测试（推荐，立刻能做）

你现在就在 Claude Code 里。把产品 prompt 直接喂给我就行。

**做法**：在这个对话里说"切换诊断模式"，把产品版 System Prompt 贴给我。然后贴你的文字，看我输出的诊断报告。

**优势**：零配置，现在就能做
**劣势**：同一对话里既有开发讨论又有产品测试，上下文会混

**更好的做法**：开一个新的 Claude Code 会话专门做测试。
1. VSCode 里 Ctrl+Shift+P → "Claude: New Conversation"
2. 在新会话里贴产品 prompt + 你的文字
3. 看诊断结果

### 方案 B：用 API 直连测试

你已经配好了 Claude API Key（不然 Claude Code 跑不起来）。用 PowerShell 直接调 API：

```powershell
# 把这段存成 test-diagnosis.ps1
$body = @{
    model = "claude-haiku-4-5-20251001"
    max_tokens = 1024
    system = @"
你是一个写作诊断工具。[这里粘贴完整的产品 System Prompt]
"@
    messages = @(
        @{role = "user"; content = "[这里粘贴要诊断的文字]"}
    )
} | ConvertTo-Json -Depth 10

$response = Invoke-RestMethod `
    -Uri "https://api.anthropic.com/v1/messages" `
    -Method Post `
    -Headers @{
        "x-api-key" = "你的API_KEY"
        "anthropic-version" = "2023-06-01"
        "content-type" = "application/json"
    } `
    -Body $body

$response.content[0].text
```

**跑起来**：PowerShell 里 `.\test-diagnosis.ps1` → 看终端输出

> 如果你的 API Key 是从第三方代理拿的（非 api.anthropic.com），把 URI 换成代理地址即可。

## 二、部署：国内可用的托管平台

Vercel/Netlify 在国内访问不稳定。下面这些国内平台可替代：

### 静态网页托管（你的 MVP 只需要这个）

| 平台 | 免费额度 | 国内速度 | 推荐度 |
|------|---------|---------|--------|
| **腾讯云 EdgeOne Pages** | 有免费额度 | ★★★★★ | ⭐ 最推荐 |
| **阿里云 OSS + CDN** | 小额付费 | ★★★★★ | 备选 |
| **Cloudflare Pages** | 完全免费 | ★★★☆☆ | 可用但慢 |
| **Gitee Pages（码云）** | 免费 | ★★★★★ | 需实名认证 |

**推荐方案**：先用 Cloudflare Pages（零成本启动 + 不需要备案），用户访问慢但能用。等你验证了付费意愿再迁移到腾讯云。

### Cloudflare Pages 部署步骤

1. 注册 cloudflare.com（可访问，不需要备案）
2. 把你的网页代码推到一个 GitHub 仓库
3. Cloudflare Pages → 连接 GitHub → 自动部署
4. 赠送域名 `xxx.pages.dev` — 国内可访问

**为什么先选 Cloudflare 而不是腾讯云**：
- 不需要域名备案（备案要 20 个工作日）
- 完全免费
- 连接 GitHub 自动部署
- 后续随时可以绑自己的域名

等你有 50 个付费用户了，再买域名 + 备案 + 迁移腾讯云。

## 三、API 调用：产品后端怎么接

你的网页需要调用 Claude API。但国内服务器直接调 api.anthropic.com 会超时。

### 解决方案：Cloudflare Workers 做 API 代理

```
用户浏览器 → 你的网页 → Cloudflare Worker（代理） → api.anthropic.com → 返回诊断
```

Cloudflare Worker 在国内和海外之间做了加速，延迟可接受。

免费的 Worker 每天 10 万次请求——够你用很久。

**具体做法**（你不需要会——给 lovable.dev 或 Cursor 说这些需求就行）：
1. 在 Cloudflare Workers 部署一个代理脚本（10 行代码）
2. 网页调用自己的 Worker 而不是直接调 Anthropic
3. Worker 转发请求到 Anthropic，加上 API Key

### 备选：直接用国内中转 API

如果你用的是 AIHub 等中转平台——它们的 API 地址国内直连，不需要 Worker 代理。更简单。

先手动。等你一天要发超过 10 个激活码的时候，再考虑自动化。
