## 1. 架构定位

### 动作句在 Hermes 管道中的位置

```
L2 六维分析 ──→ SentenceAnalysis[]
       │
       ▼
L3 颜色映射 ──→ ColoredSentence[]  （颜色 + 原始分析数据）
       │
       ▼
L4 推进引擎 ──→ 诊断报告 + ★ 动作句    ← 本规格定义的对象
       │
       │  动作句 = 颜色手势 + 焦距证据 + 体裁方向
       │  颜色手势来自 §3（六色信号基型）
       │  焦距证据来自 §4（焦距→动作词汇映射）
       │  体裁方向来自 §5（7 种体裁的推进方向库）
       │
       ▼
L5 界面渲染
```

### 动作句是什么

**动作句是 L4 给用户的推进输出——一行或一段指向具体方向的话。** 不是诊断报告的全部；诊断报告包含 X/Y/Z 三层分析，动作句是 Z 层的落地——"看见之后，往哪走"。

| 是什么 | 不是 |
|--------|------|
| 从文本中具体位置出发的方向指向 | 笼统的写作建议 |
| "这里可以往 X 方向走" | "这里应该写成 X" |
| 门是开的，路自己走 | 替用户把路走完 |
| 体裁原生词汇（诗说意象、叙说因果） | 跨体裁通用套话 |

### 与 G-1 焦距引擎的关系

- G-1 定义**分析什么**——六维焦距的扫描协议和约束边界
- G-5 定义**说什么**——分析结果如何转化为推进语言
- G-1 的 §3-§8 每个焦距有输出模板（X/Y/Z 层嵌入示例），G-5 将这些示例系统化为可参数化的模板

## 2. 设计原则

### 2.1 铁律驱动的语言约束

| 铁律 | 对动作句的约束 |
|------|--------------|
| #9 推≠替写 | 动作句指向方向，不指向具体写法。"这里可以往 X 走" ✓ / "这里应该写成 X" ✗ |
| #10 动作句优先 | 用"X 在这里是可能的"、"读者在等 Y"——保留镜子不强制语气 |
| #0 示范豁免 | 需要 ≤15 字微型示范让方向变得具体可感时可用 |
| #2 不评价好坏 | 不说"这个意象用得精准"——说"这个意象在第三句出现后，第四句被展开了" |
| #7 指向文本不指向人格 | 说"这段文字让读者感到……"——不说"你是一个……的人" |

### 2.2 动作句的三层结构

每个动作句由三层信息融合而成：

```
动作句 = 颜色手势 + 焦距证据 + 体裁方向
```

| 层 | 来源 | 作用 | 示例 |
|----|------|------|------|
| **颜色手势** | L3 颜色信号 | 决定动作句的**句型**（停/看/注意/想/知道/认识） | "注意——"、"看见了吗——" |
| **焦距证据** | L2 分析结果 | 提供**文本锚点**——什么位置、什么现象 | "第三句的'镜光浮影'之后，意象链断了" |
| **体裁方向** | 体裁透镜 | 提供**推进词汇**——该体裁下可往哪走 | "那个意象还没落地——它需要一个动作" |

### 2.3 语言一致性

- 输出语言 = 输入文本主体语言（中文→全中文，英文→全英文）
- 透镜中的分析维度术语不出现在用户可见输出中
- 体裁方向词汇全部翻译为目标语言

### 2.4 输出长度

- 动作句是诊断报告中 Z 层方向的落地——不单独成段
- 中文诊断总量 ≤500 字，英文 ≤250 词
- 动作句本身 1-2 句——点到为止

## 3. 六色信号 → 六种动作句型

L3 输出的颜色信号决定动作句的**基本手势**。以下是六种颜色对应的基型动作句型——它们是参数化模板，`[ ]` 中的内容由焦距证据和体裁方向填充。

### 3.1 🔴 胭脂红 — 卡点·停

**信号含义**：这里有什么在阻碍读者——断裂/矛盾/缺口。

**基型句型**：

```
"这里停下来——[文本具体位置]，[焦距证据：什么断了/缺了/矛盾了]。
 读者在这个位置[效果：被卡住/需要回头/被迫自己填/滑开了]。"
```

**手势词汇**：停下来 / 卡住了 / 这里缺了什么 / 读者在这里需要回头

**禁止**：
- ✗ "这里写得不好" — 不说评价
- ✗ "你应该这样改" — 不替写
- ✗ "这个断裂说明你……" — 不指向人格

**正确示例**：
> "这里停下来——第三段开头'因此'之前，缺了一步。读者从第二段的'写作不能教'跳到'真正的问题是'——中间那个'所以技巧到底能不能教'没有被写出来。读者在这个位置被迫自己推理。"

### 3.2 🟡 琥珀黄 — 模式·看

**信号含义**：看见了吗——这个模式在重复。≥2 次同模式触发。

**基型句型**：

```
"看见了吗——[模式描述]在[位置1]和[位置2]重复出现。
 这不是偶然——这是文本在[焦距归因：做什么事/产生什么效果]。"
```

**手势词汇**：看见了吗 / 在重复 / 这不是偶然 / 文本在——

**禁止**：
- ✗ "你有一个坏习惯" — 不贴标签
- ✗ "建议你改掉这个模式" — 不替决定
- ✗ 只说重复不说效果 — 模式必须连接到它在读者身上产生的效果

**正确示例**：
> "看见了吗——'他没应'之后，连续四句以'他'开头（'他脚边的影子''他爷爷种的树''他爹浇过的树''他爬过的树'）。这不是偶然——文本在用主语重复把读者的注意力锁在李建国身上，外面的一切（儿子、电话、推土机）都进不来。"

### 3.3 🔵 钢蓝 — 推进·注意

**信号含义**：注意——这里有一个可以走的方向。未展开的伏笔/意象/论点。

**基型句型**：

```
"注意——[未展开元素]在[文本位置]被引入了，但之后它什么都没做。
 它可以往[体裁方向]走——[具体方向：不是'应该写成什么'，是'往哪个方向看']。"
```

**手势词汇**：注意 / 这里有一个方向 / 还没被用完 / 可以往——走

**禁止**：
- ✗ "你应该写……" — 不替写
- ✗ "这里可以展开成……" + 详细方案 — 给方向不给答案
- ✗ 在没有方向时说"你可以随便写" — 空鼓励

**正确示例**：
> "注意——'那个没说完的名字'在第四句被引入后，全文再也没出现过。它被'裹着'——但你把它放进了文本。它可以往名字的方向走：不是揭开名字，是让'没说完'做一件事。"

### 3.4 🟣 堇紫 — 暗层·想

**信号含义**：想一想——文本下面还有东西。隐含假设/未说之物/价值预设。

**基型句型**：

```
"想一想——文本下面还有[隐含层：前提/假设/未说之物]。
 这个[隐含层]在[文本位置]被依赖了——但它没有被写出来。
 你不需要回答它。你只需要知道它在那里。"
```

**手势词汇**：想一想 / 文本下面还有 / 被依赖了但没被写出来 / 不需要回答——只需要知道

**禁止**：
- ✗ "你的潜意识在……" — 不做心理诊断
- ✗ "这暴露了你的……" — 不指向人格
- ✗ 用批判替代分析 — 只反射文本自身的隐含结构

**正确示例**：
> "想一想——文本下面还有一层。你在质疑'规划'，但整篇文字依赖了一个没说出来的前提：'人类的规划应该为个人的情感体验预留位置'。这个前提本身没有被论证——它被当作自明的东西。你不需要论证它。你只需要知道它在那里。"

### 3.5 ⚫ 鼠灰 — 数据·知道

**信号含义**：知道一下——量化指标。不独立成句，作为其他信号的辅助证据。

**基型句型**：

```
"知道一下——[指标] = [数值/定性描述]。
 这意味着[对其他焦距信号的支撑：负担/密度/分布]。"
```

**手势词汇**：知道一下 / 顺便一提 / 作为参考

**禁止**：
- ✗ 独立输出数字 — 数字永远是辅助，不单独构成诊断
- ✗ "可读性指数偏高" — 不说术语，说读者感受
- ✗ 用数字替代分析 — 数字是证据不是结论

**正确示例**：
> "知道一下——这段文字的平均句长 35 字，但第三段最后一句 82 字。读者在那个位置的信息负担突然翻倍——刚好在你引入'秩序'这个概念的位置。"

### 3.6 🟢 松绿 — 惯性·认识

**信号含义**：认识你自己——这是你反复出现的模式。跨文本指纹命中。

**基型句型**：

```
"认识你自己——连续 N 次在[场景/情境]中使用[模式]。
 这是你的惯性。不是要改——是要看见。"
```

**手势词汇**：认识你自己 / 这是你的惯性 / 不是要改，是要看见 / 你反复在——

**禁止**：
- ✗ "你总是……" — 不说"总是"，说"连续 N 次"
- ✗ "这个模式不好" — 不评价惯性
- ✗ 在非"我的文字"模式下触发 — 松绿仅在"我的文字"模式激活

**正确示例**：
> "认识你自己——连续 4 次在写到情感高潮时，下一句转向天气或环境描写。这是你的惯性——不是要改，是要看见。"

## 4. 焦距 → 动作词汇映射

每个焦距产出特定类型的分析发现。这些发现是填充动作句 `[焦距证据]` 槽位的材料。以下定义每个焦距的**证据词汇**和**方向词汇**——它们是组装动作句的"零件"。

### 4.1 语言层 → 动作词汇

| 发现类型 | 证据词汇（描述现象） | 方向词汇（指向推进） |
|---------|-------------------|-------------------|
| 句法重复 | "连续 N 句以 [X] 开头"、"全篇 [Y] 结构出现了 N 次" | "这个节奏在 [位置] 之后——要不要破一下？" |
| 词性聚集 | "[词性] 集中在 [段落]"、"[动词类型] 占了 [比例]" | "全是 [动词类型]——缺了什么动作？" |
| 语态偏向 | "被动语态集中在 [段落]"、"[N]% 的句子主语是 [X]" | "主语一直是 [X]——如果换成 [Y] 会怎样？" |
| 句长突变 | "从 [短句] 到 [长句]，长度比 1:[N]" | "那个突变在 [位置]——它是故意的吗？" |
| 修辞标记 | "[修辞手段] 在 [位置] 连续出现" | "这个修辞被用了 [N] 次——第一次和最后一次之间发生了什么？" |

### 4.2 语义层 → 动作词汇

| 发现类型 | 证据词汇 | 方向词汇 |
|---------|---------|---------|
| 意象链断裂 | "'[意象A]'在 [位置] 被引入，后续没有回声" | "这个意象还没落地——它需要一个动作" |
| 关键词缺席 | "全文的核心词从未被直接命名" | "你在写 [X]——但'[X]'这个词一直没出现" |
| 语义漂移 | "'[词]'在 [位置1] 和 [位置2] 含义不同" | "同一个词做了两件事——要分开吗？" |
| 语义场冲突 | "[场A] 和 [场B] 并置但无第三物" | "它们站在一起了——还没互相改变" |
| 意象未收束 | "'[意象]'被展开了但没被收束" | "它还在悬着——你打算让它落吗？" |

### 4.3 情感层 → 动作词汇

| 发现类型 | 证据词汇 | 方向词汇 |
|---------|---------|---------|
| 情感突转 | "情感调性在 [位置] 突变——从 [A] 到 [B] 没有预警" | "那个转弯——读者准备好了吗？" |
| 情感空白 | "预期应有情感反应的位置——文本沉默了" | "读者在那个位置等一个回应——文本没给" |
| 情感堆叠 | "[N] 个情感词在短区域内互相稀释" | "三个情感叠在一起——哪个是你真正在说的？" |
| 情感回避 | "文本接近 [敏感点] 后迅速移开" | "快到了——然后转向了。[位置] 之后去了别的地方" |
| 命名vs呈现 | "文本在'说'情感——不是'呈现'情感" | "'我很焦虑'是解释——'我看了三次手机'是观察" |

### 4.4 结构层 → 动作词汇

| 发现类型 | 证据词汇 | 方向词汇 |
|---------|---------|---------|
| 因果断裂 | "从 [A] 到 [C]——中间缺了 [B]" | "读者需要自己填的那一步——你写了吗？" |
| 并列失衡 | "[A] 占了 [N] 段，[B] 只有一句" | "读者会问——[B] 就这么完了？" |
| 头重脚轻 | "前 [N] 段信息密度远高于后段" | "重心在前面——后面在滑行" |
| 段落功能模糊 | "[段落] 读完后不知道它在做什么" | "这一段在文本里的角色是什么？" |
| 结构漂移 | "文本开头是 [A] 结构，结尾变成了 [B]" | "结构的规则在 [位置] 变了——读者知道吗？" |

### 4.5 语用层 → 动作词汇

| 发现类型 | 证据词汇 | 方向词汇 |
|---------|---------|---------|
| 预设读者错位 | "文本预设读者知道 [X]——但没给入口" | "不知道 [X] 的读者——还能进来吗？" |
| 说服力衰减 | "读者在 [位置] 开始滑开" | "那个位置之后——读者还在被说服吗？" |
| 语气漂移 | "语气在 [位置] 从 [A] 变成 [B]" | "两个声音——是故意的吗？" |
| 修辞目的模糊 | "读完不确定文本想让你做什么" | "这段文字想让读者——信？做？感受？理解？" |
| 叙述者位置不稳 | "说者的身份在 [位置1] 和 [位置2] 不同" | "你是谁在说话？专家？朋友？目击者？" |

### 4.6 批判层 → 动作词汇

| 发现类型 | 证据词汇 | 方向词汇 |
|---------|---------|---------|
| 隐含前提 | "这个推理依赖了 [前提]——但未被论证" | "不接受这个前提的读者——还能被触及吗？" |
| 价值预设 | "'显然'/'当然'后面的东西被当作了共识" | "那个'当然'——对谁来说是当然的？" |
| 回避标记 | "文本在 [位置] 接近 [话题] 后绕开" | "你靠近了——然后去了别的地方" |
| 权力关系 | "[角色A] 在文本中拥有 [X] 权力但未被反思" | "谁在说话？以什么资格？" |
| 框架效应 | "文本选择了 [框架A]——排除了 [框架B]" | "如果换一个框架看同一件事——什么会被看到？" |

### 4.7 焦距词汇使用规则

1. **不引用术语**：证据词汇和方向词汇是给 L4 的内部参考——用户输出中不出现"语言层"、"批判层"等术语
2. **体裁翻译**：同一个焦距词汇在不同体裁中需要翻译为体裁原生语言（见 §5）
3. **证据优先**：先说文本里有什么（证据），再说这可能意味着什么（方向）
4. **方向不强制**：方向词汇指向可能性，不指向"应该"——"要不要破一下？" ✓ / "应该破一下" ✗

## 5. 体裁 × 焦距动作句模板

每个体裁有其核心焦距（★★★）和推荐焦距（★★）。核心焦距的动作句模板需详细定义；推荐焦距给出简化模板；可选焦距（★）仅给出最低限度模板——因为大多数情况下它们被跳过。

模板中的标记：
- `{P}` = 文本位置（句号/段落号）
- `{E}` = 焦距证据（从 §4 的对应焦距词汇中选取）
- `{D}` = 体裁方向（从本节的体裁方向库中选取）
- `{W}` = 具体文本词/意象/概念（从用户文本中提取）

### 5.1 诗性/意象

**焦距优先级**：语义 ★★★ / 语言 ★★★ / 情感 ★★ / 批判 ★★ / 结构 ★ / 语用 ★

#### 5.1.1 语义层（★★★ 核心焦距）→ 意象链动作句

结合颜色信号 🔵 钢蓝（未展开意象）和 🟡 琥珀黄（意象模式）：

```
模板 A（意象未落地·钢蓝）：
"注意——'{W}'在{P}被引入了。它出现了——但它什么都没做。
 这个意象还没落地。它可以往{D}走——不是解释它，是让它做一个动作。"

模板 B（意象间无张力·钢蓝）：
"'{W1}'和'{W2}'在{P}放在了一起——但它们只是站在一起。
 两个意象之间还没有产生第三物。它们可以互相{D}——不是并列，是互相改变。"

模板 C（意象链断裂·琥珀黄）：
"看见了吗——从{P1}的'{W1}'到{P2}的'{W2}'，中间有一个跳跃。

┌─────────────────────────────┐
│ 步骤3：体裁方向翻译          │
│   从体裁透镜获取方向库（§5）  │
│   将 §4 的通用方向词汇       │
│   翻译为体裁原生语言          │
└──────────┬──────────────────┘
           │ 颜色手势 + 焦距证据 + 体裁方向
           ▼
┌─────────────────────────────┐
│ 步骤4：组装成句              │
│   填充参数槽位               │
│   校验铁律合规                │
│   输出完整动作句              │
└─────────────────────────────┘
```

### 6.2 多信号共存时的优先级

当一句话触发多个颜色信号时，动作句按以下优先级生成：

```
胭脂红（卡点）> 堇紫（暗层）> 钢蓝（推进）> 琥珀黄（模式）> 鼠灰（数据）
```

- 胭脂红优先——读者卡住了是最紧急的信号
- 堇紫次之——隐含层的问题比可展开的方向更深
- 同一动作句中不混合两个颜色手势——如果需要说两件事，分两句说

### 6.3 体裁核心焦距的信号增强

当信号来自体裁 ★★★ 核心焦距时，动作句可以比常规多 1 句——因为这是该体裁最核心的分析维度：

- ★★★ 焦距的动作句：最多 3 句
- ★★ 焦距的动作句：最多 2 句
- ★ 焦距的动作句：1 句（如果触发）

### 6.4 无信号时的行为

如果 L3 所有颜色信号均为空（文本无显著特征），不强行生成动作句。输出：

```
"这段文字目前没有让我停下来的地方——不是因为它完美，是因为我还没找到进入它的角度。
 如果你告诉我你在写什么、卡在哪里——我可以更精确。"
```

## 7. 质量校验清单

每条动作句在输出前必须通过以下校验：

### 7.1 铁律合规

| # | 检查项 | 违规示例 | 合规改写 |
|---|--------|---------|---------|
| 1 | 是否指向文本位置？ | "你的论证有问题" | "在'{P}'，从'{W1}'到'{W2}'之间——" |
| 2 | 是否评价了好坏？ | "这个比喻很精彩" | "这个比喻让读者从'{W1}'看到了'{W2}'" |
| 3 | 是否给了空鼓励？ | "慢慢来，你已经很棒了" | 无替代——直接删除 |
| 4 | 是否指向了人格？ | "你是一个回避型写作者" | "文本在{P}靠近了{W}然后转向了" |
| 5 | 是否替用户写了？ | "这里应该写成'{W}'" | "这里可以往'{D}'方向走" |
| 6 | 方向是否强制？ | "你应该做 X" | "X 在这里是可能的" / "要不要——？" |
| 7 | 输出语言是否一致？ | 中文诊断中出现 "hedging"、"alliteration" | 描述现象——不引外文术语 |

### 7.2 结构完整性

| 检查项 | 标准 |
|--------|------|
| 是否有文本锚点？ | 至少包含 1 个具体的文本位置（句号/段落号/词） |
| 是否有焦距证据？ | 描述了文本中可追踪的现象——不只是印象 |
| 是否有方向？ | 指向了一个具体的可能性——不是"继续加油" |
| 方向是否在体裁内？ | 诗不说"论点"、叙不说"意象"、论不说"场景" |
| 示范是否 ≤15 字？ | 超过 → 撤回示范，只留方向 |

### 7.3 自检问句

在输出每句动作句之前，问自己：

1. **"如果用户照着这个方向走——他是在写自己的东西，还是在写我建议的东西？"** → 如果是后者，撤回重写
2. **"这句话能让用户接上一句吗？"** → 如果不能——动作句没完成它的工作
3. **"如果用户说'不对'——这句话还能站住吗？"** → 如果它依赖了猜测——撤回猜测，多说"文本里可以看到……"

## 8. 集成说明

### 8.1 与 L4 引擎的关系

本规格是 L4 推进引擎的**语言输出层**设计。L4 的实现需要：
1. 从 L3 接收 ColoredSentence[]
2. 按 §6.1 组装流程生成动作句
3. 使用 §3 的基型句型 + §4 的焦距词汇 + §5 的体裁方向库
4. 通过 §7 的质量校验

本规格不定义 L4 的**信号聚类逻辑**或**焦距选择逻辑**——这些属于 L4 引擎的内部实现。

### 8.2 与透镜文件的关系

各透镜文件（`lenses/*.md`）的质量三角和 X→Y→Z 映射表提供**分析框架**。本规格提供**输出语言**。

- 透镜文件 §5.1-§5.6 的"体裁方向库"可直接提取到对应透镜文件的 `## 焦距优先级与特化指令` 章节中，作为"动作句方向词汇"小节
- 透镜文件现有的"例句"段落（如 poetic.md 末尾的两条例句）已经是在应用本规格的模板——可以替换为对本规格的引用

### 8.3 与 SKILL.md 的关系

SKILL.md 的"结构化输出格式"定义了动作句的**包装格式**（体裁标签 + X/Y/Z 自然段落）。本规格定义段落内部的**句子级语言模板**。

两者配合：
- SKILL.md 说"输出什么结构"
- G-5 说"每个结构里的句子怎么说"

### 8.4 实现阶段

| 阶段 | 交付 | 使用本规格的方式 |
|------|------|----------------|
| Phase 1（当前） | Skill `/text-lens` 在 Claude Code 中运行 | LLM 加载本规格作为参考——手动匹配模板 |
| Phase 2 | Web 编辑器 L4 引擎 | 代码实现 §6.1 组装流程——自动化模板填充 |
| Phase 4+ | 完整 Hermes 管道 | L2→L3→L4 全链路自动化——模板成为 L4 输出生成器 |

### 8.5 与 G-1 焦距引擎的协同

- G-1 的 §10.2 定义了维度冲突处理规则（语义层 > 语言层，等等）
- G-5 的动作句在遇到维度冲突时，遵循 G-1 的优先级——优先报告高优先级焦距的发现
- G-1 的 §10.3 最少输出原则（X:1-2 信号 / Y:1 成因 / Z:1 方向）直接约束 G-5 的动作句数量

## 附录 A：动作句反模式

以下是不该出现的动作句形态——来自铁律和产品迭代中的教训：

| 反模式 | 示例 | 为什么错 | 正确替代 |
|--------|------|---------|---------|
| **空洞命名** | "这段文字的主题是自由" | 没说文本里哪里有——无锚点 | "第三段引入了'自由'——但之后全文未再出现这个词" |
| **假装提问** | "你有没有想过……？" | 答案在文本里——空问题。铁律 #6 | "文本里'{W}'——但你没给它名字。它在等你命名。" |
| **替感受** | "读者会被感动" | 不说读者的感受——只描述文本在读者身上可能产生的效果 | "读者在这个位置可能需要停下来——'{W}'之后有一个空白" |
| **弱化建议** | "或许你可以考虑……？" | "或许/可能/大概"——不确定句式，铁律禁止 | "这里可以往{D}走——'{W}'在等你" |
| **抽象收尾** | "写作就是这样的过程" | 从文本飞到了哲学——没有可操作的下一步 | 删除——回到文本中的具体位置 |
| **过度示范** | 给出一整句替换写法 | 替写——铁律 #1、#9 | 给方向 + ≤15 字微型示范（铁律 #0） |
| **人格标签** | "这是你的焦虑型依恋模式" | 指向人格——铁律 #7 | "文本在{P}靠近了{W}——然后停了" |

## 附录 B：动作句示例全集

以下每句是对应体裁下的一次完整动作句输出——作为模板实现的参考基准：

### 诗性
> "注意——'镜光浮影'在第三行被引入，之后'风飘渺'和'落井石'都来了——但镜光里的那个影子是什么，从头到尾没有被写出来。这个意象还没落地——它需要一个动作。不是解释它，是让它触碰什么。"

### 叙事
> "这里停下来——从李建国听到'电话'到他碾烟头——中间他什么都没说。读者在那个沉默里等了五句话。他的人物的内心——在碾烟头的那几秒钟里发生了什么？不是'他很难过'——是膝盖咔嚓响的时候他忽然想不起来的那个东西。"

### 论述
> "想一想——文本下面还有一层。'写作不能教'这个信念——你分析了它的来源（让人舒服），但你没有检验它本身。如果写作的可教部分和不可教部分之间的那条线——是可以移动的？那个检验——是你真正想写的东西。"

### 技术
> "这里停下来——'{W}'在第二段第一次出现，但它的定义在第五段才来。中间三段——读者在用猜的意义读。如果读者猜错了——后面的所有操作都建立在错误的理解上。"

### 对话
> "看见了吗——A 第三次提起'{W}'。每一次，B 都回到了'{W2}'。'{W}'在这个对话里——是不被允许的话题。但 A 一直在试。那个坚持——在说什么？"

### 内省
> "这里停下来——你说'我可能就是这种人吧'。这是止步——不是观察。你在用一个标签关闭追问。在你说这句话之前的那个瞬间——你看到了什么？不用解释。描述它。"

### 通用
> "注意——'{W}'在开头和结尾各出现了一次。第一次它是一个问题，最后一次它变成了一个答案。但中间——它怎么从问题变成答案的——没有被写出来。那个转变的过程。如果你知道这是什么类型的文本，我可以更精确。"
