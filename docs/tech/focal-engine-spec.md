## 1. 架构定位

### 焦距引擎在 Hermes 架构中的位置

```
L1 句子分解 ──→ 句单元列表
       │
       ▼
L2 六维分析引擎 ←── 本规格定义的对象
       │
       │  每个焦距 = 一个分析原语
       │  体裁透镜 = 焦距的选择器 + 优先级排序器
       │  X→Y→Z = 焦距分析的输出组织框架
       │
       ▼
L3 颜色映射 ──→ 信号颜色 → 渲染指令
       │
       ▼
L4 Hermes 推进引擎 ──→ 动作句
```

### 核心概念

| 概念 | 是什么 | 不是 |
|------|--------|------|
| **焦距 (Focal Dimension)** | 文本的**一个分析切面**——从特定角度观察文本的协议 | 不是独立的分析模式 |
| **体裁透镜 (Genre Lens)** | **焦距的选择器和优先级排序器**——决定该体裁下哪些焦距重要 | 不是分析原语本身 |
| **X→Y→Z** | 焦距分析结果的**输出组织框架**——三层递进呈现 | 不是焦距本身 |

### 关键设计决策

1. **焦距是正交于体裁的**：同一个"语言层"焦距，在诗性文本中看意象密度和节奏断裂，在技术文本中看术语一致性和被动语态——分析原语相同，触发条件和评估标准随体裁变化。
2. **焦距不独立输出**：不产生"语言层分析结果"这样的独立段落。焦距分析的结果通过 X→Y→Z 框架融合输出。
3. **数字层不独立成色**：数字层（ARI、句长分布等）作为辅助数据注入其他六个焦距，不产生独立的颜色信号。
4. **置信度来自焦距覆盖度**：≥3 个焦距有明确文本依据 → 高置信度；1-2 个 → 中；0 个 → 低。

## 2. 焦距与 X→Y→Z 的映射

每个焦距主要贡献于 X→Y→Z 的某一层，但不独占：

| 焦距 | 主要贡献层 | 次要贡献层 | 说明 |
|------|----------|----------|------|
| 语言层 | **X 表面效果** | Y 结构动力学 | 句法/用词是读者最直接感知的表面效果；重复模式可上浮为结构信号 |
| 语义层 | **Y 结构动力学** | X 表面效果 | 意象链/主题连贯性是表层之下的组织原则；语义断裂也可直接表现为表面矛盾 |
| 情感层 | **Y 结构动力学** | Z 揭示与方向 | 情感调性是文本的组织力之一；情感空白/回避指向未完成的方向 |
| 结构层 | **Y 结构动力学** | X 表面效果 | 文本架构是核心结构层；段落功能混乱也可直接表现为阅读障碍 |
| 语用层 | **Z 揭示与方向** | Y 结构动力学 | 读者效果/修辞目的是方向性最强的焦距；语用失败也可反映结构问题 |
| 批判层 | **Z 揭示与方向** | — | 隐含假设/未说之物天然指向方向——"你绕过了什么" |

```
X 表面效果 ←── 语言层 ──────────── 读者直接感知的部分
           ←── 语义层 (次要)
           ←── 结构层 (次要)

Y 结构动力学 ←── 语义层 ────────── 表层之下的组织原则
            ←── 情感层
            ←── 结构层
            ←── 语言层 (次要)
            ←── 语用层 (次要)

Z 揭示与方向 ←── 语用层 ────────── 指向未完成/未说出的
            ←── 批判层
            ←── 情感层 (次要)
```

**实际操作规则**：分析时六维并行扫描 → 按体裁优先级排序 → 取最显著的 2-3 个焦距的结果 → 通过 X→Y→Z 框架融合输出。不要求每层覆盖所有焦距。

## 3. 语言层 (Linguistic)

### 3.1 定义

观察文本的**微观表面**：句法结构、用词选择、节奏模式、修辞手段。这是读者最先感知到的文本层——在语义之前，读者已经在感受句子的长短、词汇的温度、节奏的快慢。

### 3.2 分析入口

**触发信号**（任一出现即可启动语言层扫描）：

- 句式重复：同一句型连续出现 ≥3 次（如连续以"我"开头、"当……的时候"结构）
- 词性聚集：某一词性（名词/动词/形容词）在局部区域异常密集
- 语态偏向：被动语态占比 >40%（中文："被/让/给/叫/受"结构密集；英文："be + past participle" 占比异常）
- 句长突变：相邻句子长度比 >3:1 或 <1:3
- 修辞标记：排比、反问、设问、倒装、省略——任一修辞手段连续出现

**启动问题**：

1. 句子的长度分布是怎样的？——短句连击？长句铺展？长短交替？
2. 主语是什么？——人？物？抽象概念？主语稳定还是频繁切换？
3. 动词的"温度"如何？——身体化动词（走/站/握/吞）还是抽象动词（进行/实现/体现/促进）？
4. 连接词密度：然而/因此/但是/然后/于是 的频率——句子之间是靠逻辑连接还是靠意象并置？
5. 有没有一个词或结构在重复——但用户可能没注意到？

### 3.3 分析协议

```
第一步：句法扫描
  - 统计句长分布（短 ≤15字/词，中 16-40，长 ≥41）
  - 识别句首模式（连续相同主语？连续相同句式？）
  - 标记语态异常（被动语态局部聚集区域）

第二步：用词扫描
  - 标记高频词（排除停用词后，出现 ≥3 次的实词）
  - 检查动词类型分布（身体动词 vs 抽象动词 vs 状态动词）
  - 检查修饰语密度（形容词/副词占总词数比例）

第三步：节奏与修辞
  - 识别修辞手段及其分布
  - 判断节奏模式：推进式（短句驱动）/ 铺展式（长句堆积）/ 交替式
  - 定位句长突变点——这些突变是故意的还是失控的？
```

### 3.4 约束边界

| 禁止 | 原因 |
|------|------|
| 纠正语法错误 | 镜子不批改——"被动语态密集"是有意义的信号，不是需要修复的错误 |
| 用风格偏好替代观察 | 不说"句子太长"——说"第三句从'当'到'的时候'之间堆了四个意象，读者在中途需要重新找主语" |
| 把句法特征当"缺点" | 短句连击可以是蓄力——描述效果，不预设好坏 |
| 做语法分析报告 | 不列"主谓宾定状补"——不说术语，说读者感受 |
| 对非母语文本做语法纠错 | 语法偏差可能是风格选择——只观察模式，不判断对错 |

### 3.5 输出模板

**X 层嵌入**（表面效果）：
> "第一段连续三个'当……的时候'——读者的呼吸被固定在一个节奏里。到第四句突然断开，只有四个字。那个断开让读者停了一下。"

**Y 层嵌入**（结构动力学）：
> "全篇的动词集中在'走'和'看'——身体在移动但还没有碰到任何东西。文本的触觉是悬空的。"

**禁止的输出形式**：
- ❌ "被动语态占比 45%，超过推荐值" — 不是量化报告
- ❌ "第三句是连动句，第四句是兼语句" — 不说语法术语
- ✅ "前三句的主语都是'他'——读者的注意力一直在他身上。第四句主语换成了'门'。那个门替你做了一个决定。"

### 3.6 体裁适配

| 体裁 | 优先级 | 语言层关注重点 |
|------|--------|--------------|
| 诗性/意象 | ★★★ | 节奏断裂、句法故意错位、意象密度、连接词稀疏度 |
| 叙事/故事 | ★★ | 句式变化（动作句 vs 描写句）、身体动词比例、时态一致性(EN) |
| 论述/观点 | ★ | 转折词分布（然而/但是/因此）、修辞手段（反问/排比）、强调结构 |
| 技术/学术 | ★★★ | 术语密度、被动语态比例、定义句模式、操作动词精确度 |
| 对话/交流 | ★★ | 话轮长度、句式选择（开放/封闭问句）、模糊限制语(EN: hedging) |
| 日记/内省 | ★ | 第一人称句首比例、"我觉得/我注意到/我感觉"的频率与分布 |
| 通用 | ★★ | 句长分布、主语稳定性、连接方式（逻辑 vs 联想） |

**诗性文本特化指令**：
> 语言层在诗性文本中不看"语法正确性"——看"语法被故意扭曲后产生了什么效果"。故意的主谓不搭配、词性活用、句法省略——这些都是信号，不是错误。

**技术文本特化指令**：
> 语言层在技术文本中看操作动词的精确度——"点击"vs"选择"vs"进入"vs"打开"——每个动词是否精确对应一个用户动作。也看术语密度的分布：是否在读者还没准备好时倾泻了过多术语。

## 4. 语义层 (Semantic)

### 4.1 定义

观察文本的**意义组织**：主题连贯性、意象链、语义场、关键词网络。语义层不看单个词的意思——看词与词之间、意象与意象之间、主题与主题之间怎么组织成一个意义整体。

### 4.2 分析入口

**触发信号**：

- 意象/主题跳跃：相邻段落之间的语义距离 > 读者可以自然追踪的范围
- 关键词缺席：文本的核心主题在文中从未被直接命名
- 语义漂移：同一个词在不同位置的含义发生了变化，但变化未被标记
- 意象链断裂：一个意象被引入后，后续文本中没有它的回声/变形/收束
- 语义场冲突：两个互斥的语义场被并置但未产生第三物（只是"站在一起"）

**启动问题**：

1. 这篇文章的"主题词"是什么？——它在文中出现了几次？每次出现的上下文是否一致？
2. 意象/概念之间的连接是什么类型的？——相似性（隐喻链）？差异性（对峙）？时间性（先后）？因果性（因为所以）？
3. 有没有一个词/意象被引入了，但后续再也没有被处理？——它出现了，但它什么都没做。
4. 文本的"语义中心"在哪里？——有没有一个核心意象/概念，其他东西围绕它组织？还是多中心/无中心？

### 4.3 分析协议

```
第一步：语义场识别
  - 提取文本中出现的语义场（感官域 / 情感域 / 概念域 / 行动域）
  - 标记每个语义场的出现位置和密度
  - 检查语义场之间的过渡——是平滑渐变还是突然切换？

第二步：意象/概念链追踪
  - 追踪核心意象/概念的出现序列
  - 每次出现时意象做了什么？（被引入 / 被展开 / 被变形 / 被对照 / 被收束）
  - 标记"未完成的意象"——被引入但未被展开、被展开但未被收束

第三步：连贯性诊断
  - 主题是否可被一句话概括？（能 → 有中心；不能 → 多中心或无中心）
  - 如果多中心——中心之间的关系是什么？（并列 / 层级 / 冲突 / 无关）
  - 如果有断裂——断裂在哪个位置？读者在哪个句子之后开始"跟丢"？
```

### 4.4 约束边界

| 禁止 | 原因 |
|------|------|
| 翻译意象（"这个意象的意思是……"） | 意象不需要翻译——翻译杀死意象 |
| 替作者建立他不曾建立的连接 | "A 和 B 可以联系起来"——如果文本里没连，镜子不替连 |
| 解释隐喻（"A 象征着 B"） | 隐喻的力量在不确定性中——解释拿走力量 |
| 用"主题不明确"当诊断 | "主题不明确"不是诊断——"第三段引入了'自由'，但之后全文未再出现这个词"才是 |
| 做文献综述式的语义分析 | 不引外部知识——只看文本内部的语义组织 |

### 4.5 输出模板

**X 层嵌入**（表面效果）：
> "第一段的意象序列——水、站起来的身体、骨头的声音、月光碎片——每个意象都引向下一个，但到'鳞片'的时候，方向变成了'裹着名字'。从身体到名字，中间有一个跳跃。"

**Y 层嵌入**（结构动力学）：
> "这里有一个意象链的断裂：'镜光浮影'被引入后，下一句的'风飘渺'和它之间没有发生任何关系——它们只是站在一起。两个意象之间没有产生第三物。"

**Z 层嵌入**（方向）：
> "'鳞片裹着名字'——那个名字从头到尾没有再出现。它被裹住了。但你把它放进了文本——你已经在靠近它了。"

### 4.6 体裁适配

| 体裁 | 优先级 | 语义层关注重点 |
|------|--------|--------------|
| 诗性/意象 | ★★★ | 意象链完整度、意象间张力（呼应/对峙/断裂/叠加）、跳跃跨度的可追踪性 |
| 叙事/故事 | ★★ | 主题一致性、象征物功能（是否被充分使用）、细节的语义负载 |
| 论述/观点 | ★★ | 关键词定义稳定性、概念漂移检测、术语闭环风险 |
| 技术/学术 | ★★ | 术语一致性（同一概念是否换名字）、关键概念定义是否在使用前给出 |
| 对话/交流 | ★★ | 话题流连贯性、语义偏移（"你说的 X 和我理解的 X 是同一个 X 吗？"）、关键词是否共享 |
| 日记/内省 | ★★ | 情感词的语义粒度（"难受"→"胸口发紧"→"像被攥住"的递进）、自我命名的稳定性 |
| 通用 | ★★ | 最小信号——文本内部的组织原则（重复/省略/连接方式） |

**诗性文本特化指令**：
> 语义层在诗性文本中是最核心的焦距。不看"意思对不对"——看意象之间有没有发生关系。两个意象放在一起，如果只是并置而没有张力（互相改变、互相质问、互相完成），它们还没开始工作。

**论述文本特化指令**：
> 语义层在论述文本中看概念的稳定性——同一个词是否在论证的不同阶段悄悄改变了含义。也看隐喻在论证中的角色：论证中的隐喻是在帮助理解还是在替代论证？

## 5. 情感层 (Sentiment)

### 5.1 定义

观察文本的**情感组织**：情感调性、情感密度、情感转向、情感空白。情感层不看"作者是什么心情"——看文本中可被追踪的情感信号：哪些地方情感密集、哪些地方情感撤退、情感在什么时候转弯。

### 5.2 分析入口

**触发信号**：

- 情感突转：情感调性在局部发生急剧改变（从描述突然变为感叹 / 从激烈突然转为平淡）
- 情感空白：读者预期会出现情感反应的位置，文本保持沉默或转向
- 情感堆叠：多个情感词在短区域内密集出现（可能互相稀释）
- 情感回避：文本接近了某个情感敏感点但迅速移开——"快到了但没进去"
- 情感命名 vs 情感呈现：文本在"说"情感（"我很焦虑"）还是在"呈现"情感（"我看了三次手机"）

**启动问题**：

1. 文本的情感温度是多少？——冷（远离/观察/分析）、温（参与/感受/回应）、热（沉浸/爆发/溢出）？
2. 情感在文本的哪个位置最密集？哪个位置最稀薄？
3. 情感有没有转向？——在哪个句子之后情感变了方向？
4. 有没有应该出现情感但没有出现的位置？——那个空白在说什么？
5. 文本是"说"情感（命名）还是"做"情感（通过意象/动作/节奏让读者感受到）？

### 5.3 分析协议

```
第一步：情感密度扫描
  - 标记情感承载词/句的位置
  - 计算情感密度的分布（前段 vs 后段、局部聚集区域）
  - 识别情感调性的基线（中性 / 沉重 / 轻盈 / 紧张 / 疏离）

第二步：情感动态追踪
  - 情感调性是否在变化？变化发生在哪个位置？
  - 变化是渐变的还是突转的？突转是蓄意的效果还是失控？
  - 情感是否存在"假收束"——文本表面上结束了但情感还在悬着？

第三步：情感空白与回避
  - 文本中是否有"预期应有但没有"的情感反应？
  - 文本是否在接近某个敏感点时撤退（词汇变化 / 话题转移 / 抽象化）？
  - 那个空白有没有被文本自身注意到？还是完全绕过？
```

### 5.4 约束边界

| 禁止 | 原因 |
|------|------|
| 替作者感受（"你一定很难过"） | 镜子不说他的感受——只描述文本中可追踪的情感信号 |
| 把"情感克制"当问题 | 克制是情感策略——不是缺失。只描述克制产生的效果 |
| 做情感分类（"这是悲伤/愤怒/恐惧"） | 不贴标签——描达情感在文本中的运动，不命名它 |
| 把"情感密集"当优点 | "情感充沛"不是诊断——"第三段三个情感词堆在一起，第二个和第三个互相抵消了"才是 |
| 对内省文本做心理诊断 | 不说"你有回避倾向"——说"你在第三段靠近了一个东西，然后停了" |

### 5.5 输出模板

**X 层嵌入**（表面效果）：
> "文本从头到尾保持了一个很平稳的情感温度——直到倒数第二句的'忽然'。读者在那个'忽然'之前没有任何预警。"

**Y 层嵌入**（结构动力学）：
> "这里有一个情感撤退：第一段写到'父亲推开门'之后，下一句没有写任何人的反应——直接跳到了第二天的天气。读者在那个门口等着一个情感回应，但文本没有给。"

**Z 层嵌入**（方向）：
> "'忽然不记得自己在找什么了'——这一句在做一件事：它在把情感从'找'的紧张释放到'不记得'的空白里。但你还没让读者看到这个空白里的东西。"

### 5.6 体裁适配

| 体裁 | 优先级 | 情感层关注重点 |
|------|--------|--------------|
| 诗性/意象 | ★★ | 意象的情感负载、情感与意象的关系（情感是通过意象呈现的还是直接说出的） |
| 叙事/故事 | ★★★ | 人物的情感驱力、情感转折与情节转折的关系、叙述者的情感距离 |
| 论述/观点 | ★ | 情感诉求与逻辑诉求的关系、情感语言在论证中的角色（强化还是替代） |
| 技术/学术 | ★ | 情感中立度——是否有意外渗入的情感语言，及其对客观性的影响 |
| 对话/交流 | ★★★ | 情感劳动分配（谁在调节气氛）、情感回应质量（承接 vs 忽略）、情感潜台词 |
| 日记/内省 | ★★★ | 情感粒度（命名 vs 呈现）、情感回避标记、情感处理深度（解释 vs 观察） |
| 通用 | ★★ | 情感调性基线 + 显著的情感转向或空白 |

**内省文本特化指令**：
> 情感层在内省文本中是最核心的焦距。不看"情绪对不对"——看情感是被观察到了还是被解释了。"我很焦虑"是解释——"我看了三次手机"是观察。解释关闭探索，观察打开探索。

**对话文本特化指令**：
> 情感层在对话中看情感劳动——谁在维持对话的温度？谁的感受被回应了，谁的被跳过了？不对情感做评判——只反射情感在互动中的流动和阻塞。

## 6. 结构层 (Structural)

### 6.1 定义

观察文本的**宏观组织**：文本架构、逻辑链、段落功能、信息层级。结构层不看句子的好坏——看句子和句子之间、段落和段落之间如何构成一个整体，以及这个整体的骨架是否在支撑文本想要做的事。

### 6.2 分析入口

**触发信号**：

- 因果断裂：前后段落/句子之间的因果关系不成立——"A 所以 C"但没有 B
- 并列失衡：同等重要的内容被赋予了不成比例的篇幅
- 头重脚轻：前段信息密度远高于后段，或反之
- 段落功能模糊：读完一段不知道它在文本中做什么（在推进论证？在举例？在过渡？）
- 结构漂移：文本开头的组织原则和结尾的组织原则不一致（开头是分类/结尾变成了叙事）

**启动问题**：

1. 文本的整体结构是什么类型的？——因果链？层级树？时间线？对比矩阵？并列清单？
2. 每个段落在做什么？——引入 / 展开 / 举例 / 反证 / 过渡 / 收束？
3. 段落之间的接口是什么？——上一段的终点和下一段的起点有没有连接？
4. 有没有一段话可以被删除而不影响整体？——如果有，它在做什么？
5. 文本的"重心"在哪里？——哪里信息最密、哪里最稀？是否失衡？

### 6.3 分析协议

```
第一步：整体结构判定
  - 判断文本的组织类型（因果/时间/层级/对比/并置/混合）
  - 检查组织类型是否与文本目的匹配
    （论证需要因果或层级；叙事需要时间或因果；技术需要层级或线序）

第二步：段落功能标注
  - 每段一个功能标签（引入/展开/深化/举例/反证/过渡/收束/其他）
  - 检查功能序列的合理性（是否缺少某些必要功能？是否有功能堆积？）
  - 检查段落过渡——接口是否明确？（上一段终点 = 下一段起点的连接物）

第三步：结构完整性检查
  - 文本的起点和终点之间——有什么从 A 状态变成了 B 状态？
  - 如果什么都没变——文本在做什么？
  - 检查结构内部的"承重墙"——哪段是结构核心，哪段可以移除？
```

### 6.4 约束边界

| 禁止 | 原因 |
|------|------|
| 替他做大纲 | 不说"你应该这样组织"——只说"读者在这个位置需要知道 X，但文本还没给" |
| 用"结构不清晰"当诊断 | "结构不清晰"不是诊断——"第二段和第三段之间没有连接——第二段结束于 X，第三段开始于 Y，它们之间的关系需要读者自己猜"才是 |
| 用预设立场评判结构 | 不预设"五段式"或"三段式"是好的——只说结构是否在做文本需要它做的事 |
| 对诗性文本强制要求结构 | 诗的逻辑不是因果——意象结构的"断裂"可能是故意的方法 |

### 6.5 输出模板

**X 层嵌入**（表面效果）：
> "读到第三段末尾，读者还在等那个'所以呢'——但第四段没有给出结论，而是开了一个新话题。"

**Y 层嵌入**（结构动力学）：
> "这篇文章的骨架是一个层级结构——先定义、再分类、再展开。但第二个子类只有一句话，第一个子类占了四段。读者在第二个子类的位置会感到——这就完了？"

**Z 层嵌入**（方向）：
> "你从'写作不能教'推到了'写作可以学'——中间跳了一步：'技巧可以教'和'天赋不需要教'之间，缺了一个连接：天赋和技巧的关系。那个缺了的位置，就是你真正想写的东西。"

### 6.6 体裁适配

| 体裁 | 优先级 | 结构层关注重点 |
|------|--------|--------------|
| 诗性/意象 | ★ | 意象序列的方向性（从什么到什么）、结构断裂的功能（是故意的还是失控的） |
| 叙事/故事 | ★★★ | 因果链完整度、场景功能（每个场景是否改变了状态）、叙事节奏（场景 vs 概括的交替） |
| 论述/观点 | ★★★ | 推理链完整度（前提→推理→结论每一步是否成立）、反证位置与处理、让步的真实性 |
| 技术/学术 | ★★★ | 信息架构类型（树形/线序/矩阵/网状）、信息层级清晰度、步骤完整性（前置条件→操作→后置状态） |
| 对话/交流 | ★ | 话题流结构——话题如何开启/偏移/截断/回归——是否形成可追踪的结构 |
| 日记/内省 | ★ | 最低限度——观察流是否有方向（从什么到什么），还是原地循环 |
| 通用 | ★★ | 文本组织原则 + 段落功能 + 起点→终点的状态变化 |

**论述文本特化指令**：
> 结构层在论述文本中是核心焦距。追踪"因此"的距离——从前提到结论，每一步之间的"因此"是否成立？中间省略了几个"因此"？读者被迫自己填充了几步？

**叙事文本特化指令**：
> 结构层在叙事中看因果功能——每个场景改变了什么？如果一个场景什么都没改变，它为什么在这里？叙事结构不是大纲——是因果链的落地。

## 7. 语用层 (Pragmatic)

### 7.1 定义

观察文本与**读者/语境**的关系：读者效果、修辞目的、语境适配度。语用层不问"文本说了什么"——问"文本在读者身上做了什么，以及这个'做'是否匹配文本的目的和语境"。

### 7.2 分析入口

**触发信号**：

- 预设读者错位：文本假设了读者知道某些信息但读者可能不知道——或反过来，解释了读者已经知道的东西
- 说服力衰减：论证在某个位置之后读者开始"滑开"——继续读但不继续被说服
- 语气漂移：文本的语气在局部发生了不协调的切换（正式→随意→正式）
- 修辞目的模糊：读完不确定文本想让我做什么——信？做？感受？理解？
- 语境不适配：文本的形式和它所在的语境不匹配（如公众发言用了私人日记的语气）

**启动问题**：

1. 这段文字在和谁说话？——它预设了什么样的读者？
2. 这段文字想让读者做什么？——相信一个观点？感受一种情绪？理解一个概念？做一个行动？
3. 读者在哪个位置开始"出戏"？——哪句话之后读者不再被文本带着走？
4. 文本的"身份"是否一致？——说者的位置是否稳定？（专家？朋友？观察者？参与者？）
5. 如果读者不是文本预设的那种人——还能被文本触及吗？

### 7.3 分析协议

```
第一步：读者预设分析
  - 文本预设读者知道什么？（专业术语？文化背景？先验共识？）
  - 这些预设是否合理？如果读者不知道——还有入口吗？
  - 文本在什么地方向读者开放，又在什么地方把读者关在门外？

第二步：修辞效果追踪
  - 文本的修辞目的是什么？（告知 / 说服 / 感动 / 推动 / 共鸣 / 挑战）
  - 文本的策略是否匹配目的？（试图说服但只给了个人经验？试图感动但全程分析式语调？）
  - 读者在哪个位置最被文本牵引？在哪个位置开始游离？

第三步：语境适配
  - 文本的语境是什么？（公开发表 / 私人记录 / 专业交流 / 亲密对话）
  - 文本的形式/语气是否适配语境？
  - 如果语境不明——文本的"语域"是否内部一致？
```

### 7.4 约束边界

| 禁止 | 原因 |
|------|------|
| 猜测作者意图（"你想表达的是……"） | 不说意图——只说文本在读者身上产生的效果 |
| 替文本选择读者 | 不说"你应该写给 X 看"——只说"文本目前预设了 X 类读者，如果你预设的是 Y，那这里有一个错位" |
| 用"说服力不够"当诊断 | "说服力不够"不是诊断——"第二段的论据是个人经验，但你主张的是一个普遍性结论——经验和结论之间，读者需要一个人数"才是 |
| 做受众分析报告 | 不列人口统计——只说文本对读者的预设和这些预设的效果 |
| 对私人写作（日记/内省）强制要求"读者意识" | 内省文本的读者就是写作者自己——不做"你应该考虑读者"的推进 |

### 7.5 输出模板

**X 层嵌入**（表面效果）：
> "文本在第二段开始使用'我们都知道'——但读者未必知道。那个'我们'是一个假设——它在邀请读者站到一个读者可能还没准备好的位置。"

**Y 层嵌入**（结构动力学）：
> "文本的目的是让读者质疑'写作不能教'这个信念——但前面三段的语气是宣布式的（'当然可以'、'真正的问题是'），不是邀请式的。读者还没被说服——就已经被告知了自己的立场是错的。这会让一部分读者在第一段就关掉。"

**Z 层嵌入**（方向）：
> "第四段最后一句'后者不舒服，但后者给了你路'——这一句在做一个动作：它把读者从'被批评'的位置拉到了'被邀请'的位置。如果你想让读者走进这个邀请——前面需要给更多的门。"

### 7.6 体裁适配

| 体裁 | 优先级 | 语用层关注重点 |
|------|--------|--------------|
| 诗性/意象 | ★ | 诗的可进入性——意象是否在邀请读者还是排斥读者；诗的"声音"是否一致 |
| 叙事/故事 | ★★ | 叙述者与读者的距离、读者张力（读者在等待什么/预测什么）、叙述可靠性 |
| 论述/观点 | ★★★ | 说服策略、读者预设、反证诚实度（是否面对最强的反方观点）、修辞诉求平衡 |
| 技术/学术 | ★★ | 读者前置知识的预设是否合理、信息是否在读者需要的时候出现、文档是否可操作 |
| 对话/交流 | ★★★ | 对话的权力关系、参与者角色、互动模式——但不对对话中的任何一方站队 |
| 日记/内省 | ★ | 最低限度——仅当文本有明显的"表演性"（写给别人看的内省）时启动 |
| 通用 | ★★ | 文本的修辞目的 + 预设读者 + 读者能否进入 |

**论述文本特化指令**：
> 语用层在论述文本中是核心焦距。看论证在读者身上产生的实际效果——读者在哪个位置开始抵抗？哪个位置开始滑开？是论据不支撑主张，还是语气提前关闭了对话？

**对话文本特化指令**：
> 语用层在对话中看互动模式——话轮的开闭、话题的控制、情感劳动的分配。不看"谁对谁错"——看"在这个互动中，什么话能说，什么话不能说"。

## 8. 批判层 (Critical)

### 8.1 定义

观察文本的**隐含层**：未明确说出的假设、价值前提、权力关系、回避的话题。批判层不看文本说了什么——看文本依赖了什么没说出来的东西才能成立。

### 8.2 分析入口

**触发信号**：

- 隐含前提：文本的推理/叙述依赖了一个未被声明的前提——如果这个前提不成立，整个结构动摇
- 价值预设：文本中隐含了某种价值判断但未将其作为论点提出（"显然"、"当然"、"毫无疑问"后面的东西）
- 回避标记：文本在接近某个话题/立场/情感时出现回避（话题转移、抽象化、沉默）
- 权力关系：文本中的参与者之间存在未被命名的权力不对称
- 框架效应：文本选择了一种描述框架而排除了其他框架——那个选择本身是一个没说出来的立场

**启动问题**：

1. 这段话若要成立——需要读者接受什么前提？这些前提被明确说出来了，还是被假设了？
2. 有什么东西在文本的边缘——被提到了但没展开、被靠近了但绕开了？
3. 文本在用什么框架看世界？——这个框架排除了什么视角？
4. 文本中谁在说话？——那个说者的位置给予了什么权力？限制了什么视野？
5. 如果读者不接受文本的隐含前提——文本还有说服力/感染力吗？

### 8.3 分析协议

```
第一步：前提提取
  - 提取文本论证/叙述依赖的核心前提（至少 1 个，最多 3 个）
  - 区分"已声明的"和"未声明的"前提
  - 检查未声明前提是否合理——如果读者不接受，会发生什么？

第二步：回避检测
  - 识别话题/立场的接近-回避模式
  - 标记"本该但没有"的内容——文本提出了问题但没给出同等重量的回应
  - 检查文本的沉默区域——什么完全没有被提及？

第三步：框架反思
  - 文本采用的核心框架/隐喻是什么？（如"写作是修炼" vs "写作是表达"）
  - 这个框架排除了什么？（如果"写作是修炼"，那"玩"在哪？）
  - 框架是文本自身意识到的，还是无意识采用的？
```

### 8.4 约束边界

| 禁止 | 原因 |
|------|------|
| 做意识形态批判 | 不说"这个观点是错的"——只说"这个推理依赖了 X 前提，但 X 没有被论证" |
| 替文本"揭露"更深层的真相 | 镜子只反射文本自身暴露的隐含层——不添加文本里没有的政治/社会/心理分析 |
| 把"有隐含前提"当问题 | 所有文本都有隐含前提——问题不是"有"，是"前提与结论之间的距离太大读者跨不过去" |
| 对内省文本做心理诊断式的批判 | 不说"你在回避你的父亲问题"——只说"文本里出现了三次'算了不说这个'，每次都接一个新话题" |
| 以"批判"为名替自己站队 | 批判层不选边——反射文本的隐含结构，不给它打分 |

### 8.5 输出模板

**X 层嵌入**（表面效果）：
> "文本在第三段引入了'规划'和'秩序'这两个词——但一直没有说'秩序'是什么。读者在跟着你质疑'规划'，但不知道你站在哪个'秩序'上说这句话。"

**Y 层嵌入**（结构动力学）：
> "这段论证依赖了一个前提：'人类的规划应该为个人的情感体验预留位置'。这个前提本身没有被论证——它被当作了自明的东西。对于不共享这个前提的读者，后面的论证无法触及他们。"

**Z 层嵌入**（方向）：
> "你在最后一句问'我该住在什么样的秩序里'——但整篇文字里你还没有命名那个'秩序'。你只是说了它不是什么（规划）。它是什么——你还没写。那句话在等你。"

### 8.6 体裁适配

| 体裁 | 优先级 | 批判层关注重点 |
|------|--------|--------------|
| 诗性/意象 | ★★ | 诗选择呈现什么/省略什么——这个选择本身就是立场；诗中的权力关系（谁在说话？对谁？以什么资格？） |
| 叙事/故事 | ★ | 叙述者的价值立场是否被意识到、叙事的"道德框架"是否隐含（好人/坏人/受害者/英雄的预设安排） |
| 论述/观点 | ★★★ | 隐含前提的识别与检验、价值预设的位置、反证诚实度（是否面对了最强的反方观点）、驳论位 |
| 技术/学术 | ★ | 技术选择的隐含价值假设（"最优方案"——按什么标准？）、信息缺席（什么没被记录/测量？） |
| 对话/交流 | ★★ | 对话中的权力不对称、未说出口的预设（双方在什么前提上假装一致？）、沉默的归属 |
| 日记/内省 | ★★ | 自我叙述的框架——在用什么故事模板解释自己？什么解释框架被采用了而没有被检查？ |
| 通用 | ★ | 最低限度——仅在文本有明显未声明前提时启动 |

**论述文本特化指令**：
> 批判层在论述文本中是核心焦距。不看"观点对不对"——看论证基础："这个推理需要读者接受什么？那些需要被接受的东西——文本给理由了吗？"

**诗性文本特化指令**：
> 批判层在诗性文本中不分析"意识形态"——看诗选择呈现/省略的世界。诗省略的部分和呈现的部分之间的边界——那个边界在说什么？

## 9. 数字层 (Digital)·辅助维度

### 9.1 定位

数字层**不产生独立的颜色信号**。它分析可量化的文本指标，将数据注入其他六个焦距作为辅助证据。

### 9.2 采集指标

| 指标 | 计算方式 | 注入目标焦距 | 用途 |
|------|---------|------------|------|
| 句长分布 | 短(≤15字/词) : 中(16-40) : 长(≥41) 的比例 | 语言层 | 句法节奏的量化证据 |
| 型例比 (TTR) | 不重复词数 / 总词数 | 语义层 | 词汇丰富度的量化证据 |
| 被动语态比 | 被动结构句数 / 总句数 | 语言层 | 语态偏向的量化证据 |
| 连接词密度 | 逻辑连接词数 / 总句数 | 结构层 | 连接方式的量化证据 |
| 情感词密度 | 情感承载词数 / 总词数 | 情感层 | 情感密度的量化证据 |
| 段落长度方差 | 各段字数的标准差 | 结构层 | 结构失衡的量化证据 |
| 可读性指数 | ARI / 迷雾指数 / 中文等效 | 语用层 | 读者负担的量化证据 |

### 9.3 使用规则

1. **数字永远是辅助**——不说"可读性指数 12，偏高"；说"句子平均 35 个词，读者在中途可能需要回头找主语——这个负担在第三段最重"
2. **不独立输出数字**——数字融入其他焦距的自然语言描述中
3. **数字不能替代分析**——"被动语态 45%"不是诊断，"被动语态集中在方法描述段，操作步骤段的主语全是'系统'——读者不知道是谁在做那个操作"才是
4. **Skill 环境不强制计算**——Skill 在 Claude Code 中运行时没有计算工具，数字层指标依赖 LLM 的"感知"而非精确计算。Web App L2 引擎可以实现精确计算

### 9.4 Skill 环境简化

在 Skill（纯 LLM）环境中，数字层降级为"定性感知"：
- 不计算精确数值
- 用"密集/稀疏/均匀/突变"等定性描述替代百分比
- 当需要数字来支撑判断时，用文本位置替代统计："连续 5 句以'他'开头" > "主语重复率 83%"

## 10. 跨维度组合规则

### 10.1 维度优先级

体裁透镜通过 ★ 系统设定每个焦距的优先级。实际操作时：

1. ★★★（必须启用）→ 无条件扫描
2. ★★（推荐启用）→ 当文本有明显触发信号时扫描
3. ★（可选）→ 仅在文本对该维度有强烈信号时启用，否则跳过以节省 token

### 10.2 维度冲突处理

当两个焦距的分析结果指向不同方向时：

| 冲突类型 | 处理规则 | 示例 |
|---------|---------|------|
| 语言层 ✗ 语义层 | 语义层优先——结构动力学优先于表面效果 | 句式优美但意象链断裂 → 报告断裂，不夸句式 |
| 情感层 ✗ 结构层 | 结构层优先——组织的完整性比情感的丰富性更基础 | 情感细腻但因果链缺失 → 指向因果缺口，情感密度仅作为特征标注 |
| 语用层 ✗ 批判层 | 批判层优先——隐含前提的问题比修辞策略的问题更深 | 说服策略得当但依赖未论证前提 → 指出前提，说服策略作为次要观察 |
| 任意层 ✗ 体裁核心焦距 | 体裁核心焦距优先 | 叙事文本中结构层（★★★）的因果断裂 > 语言层（★★）的句式变化 |

### 10.3 最少输出原则

无论多少焦距有发现，最终输出时：
- X 层：取最显著的 1-2 个信号（不限焦距来源）
- Y 层：取最核心的 1 个结构成因（来自贡献 Y 层的焦距中信号最强的）
- Z 层：1 个方向（来自语用层或批判层的信号优先，因为这两个焦距天然指向方向）
- 【特征】：仅当有值得注意但不构成诊断的观察时输出

### 10.4 Token 预算分配

| 模式 | 启用焦距 | Token 预算 | 各焦距分配 |
|------|---------|-----------|----------|
| 快速透视 | 语言 + 结构 | ~800t | 语言 300t / 结构 300t / 融合输出 200t |
| 标准透视 | 语言 + 语义 + 情感 + 结构 | ~1,500t | 四个焦距各 ~300t / 融合输出 ~300t |
| 深度透视 | 全部六维 + 批判 | ~3,000t | 六个焦距各 ~400t / 融合输出 ~600t |

> 以上为 Skill 环境的估算。实际 token 消耗由 LLM 自行控制——焦距分析协议是"扫描指令"而非"输出模板"。

## 11. 透镜文件集成指南

### 11.1 集成前置理解

在修改任何透镜文件之前，必须理解焦距章节与现有结构之间的**两层关系**：

**第一层：焦距章节是"前置配置"，现有结构是"落地执行"**

```
                    ┌─ 焦距优先级与特化指令 ─┐   ← 新增（前置配置）
                    │  哪些焦距重要？        │
                    │  每个焦距在这体裁里     │
                    │  看什么？不看什么？      │
                    └──────────┬───────────┘
                               │ 控制：启用/跳过/特化
                               ▼
                    ┌─ 现有分析协议 ──────────┐   ← 不变（落地执行）
                    │  意象扫描 / 铁三角扫描   │
                    │  论证链追踪 / 话轮分析   │
                    │  观察三角 / 信息架构     │
                    └──────────┬───────────┘
                               │ 产出：分析结果
                               ▼
                    ┌─ X→Y→Z 映射表 ──────────┐   ← 不变（输出框架）
                    │  输出组织为三层结构       │
                    └──────────────────────────┘
```

焦距章节**不替代**现有分析协议——它**控制**分析协议的执行范围。类比：焦距章节是"管道开关"，决定六条分析管道中哪些打开、开到什么程度；现有分析协议是"管道内的水流"——体裁特定的分析流程。

**第二层：焦距优先级直接控制执行条件**

| 优先级 | 执行条件 | Token 行为 |
|--------|---------|-----------|
| ★★★ | 无条件执行该焦距扫描 | 消耗预算（必须） |
| ★★ | 文本出现该焦距的 ≥1 个触发信号时执行 | 消耗预算（按需） |
| ★ | 文本出现该焦距的 ≥2 个强触发信号时才执行 | 节省预算（默认跳过） |

> 这意味着：优先级矩阵不是"建议"——它是**执行条件**。如果叙事透镜中批判层标记为 ★，而输入文本没有 2 个以上的强触发信号，则批判层扫描被跳过——即使现有的"分析协议"中包含某些隐含的批判性检查。

### 11.2 集成方式

每个透镜文件在现有结构上新增一个 **"焦距优先级与特化指令"** 章节。该章节：

1. 引用本规格中的焦距定义（不重复写，只引用）
2. 标注该体裁下各焦距的优先级（★★★/★★/★）
3. 给出体裁特定的焦距分析指令（仅该体裁才需要的特化规则）

**物理位置**：焦距章节必须放置在透镜文件中**现有分析协议之前**。具体位置：

```
1. 体裁识别确认        ← 不变（最先执行——先确认体裁）
2. ★ 焦距优先级与特化指令 ← 新增（第二执行——确定分析范围）
3. 本体裁 X→Y→Z 映射表  ← 不变（输出框架——焦距分析结果如何组织）
4. 质量三角              ← 不变（体裁特定的落地检查）
5. 分析协议              ← 不变（体裁特定的分析流程——在焦距控制下执行）
6. 禁止项                ← 不变
7. 输出调整              ← 不变
8. 深度分析触发          ← 不变
```

**为什么放在这个位置**：
- 在体裁识别之后：只有确认了体裁，焦距优先级才有意义（体裁决定了 ★ 的值）
- 在分析协议之前：分析协议执行前必须先知道"哪些焦距被启用、哪些被跳过"
- 在 X→Y→Z 映射表之前：X→Y→Z 的每一层从哪些焦距取信号，由焦距优先级决定

**命名约定**：章节标题统一为 `## 焦距优先级与特化指令`（所有透镜文件保持一致——不因体裁不同而改名）。

### 11.3 焦距章节与现有结构的控制流

集成后的分析执行流程：

```
输入文本
    │
    ▼
┌─────────────────────────────┐
│ 1. 体裁识别确认              │  ← 现有结构（不变）
│    确认体裁假设成立           │
└──────────┬──────────────────┘
           │ 体裁确认 → 路由到对应透镜
           ▼
┌─────────────────────────────┐
│ 2. 焦距优先级与特化指令      │  ← 新增章节
│    读取 ★★★/★★/★ 矩阵       │
│    检查各焦距触发信号         │
│    → 生成"启用焦距列表"      │
│    → 标记"跳过焦距列表"      │
└──────────┬──────────────────┘
           │ 启用焦距 = 分析范围
           ▼
┌─────────────────────────────┐
│ 3. 分析协议执行              │  ← 现有结构（受焦距控制）
│    体裁特定的分析流程         │
│    仅扫描启用焦距的维度       │
│    跳过的焦距不执行扫描       │
│    ┌─────────────────────┐  │
│    │ 质量三角检查          │  │  ← 三角本身不变
│    │ 但三角的角与焦距对应： │  │     但扫描深度由焦距优先级控制
│    │ 意象落地 → 语义层     │  │
│    │ 意象间张力 → 语义层   │  │
│    │ 节奏呼吸 → 语言层     │  │
│    └─────────────────────┘  │
└──────────┬──────────────────┘
           │ 分析结果（各焦距产出）
           ▼
┌─────────────────────────────┐
│ 4. X→Y→Z 融合输出           │  ← 现有结构（不变）
│    X 层 ← 取最显著 1-2 信号  │
│    Y 层 ← 取最核心 1 个成因  │
│    Z 层 ← 1 个方向           │
│    【特征】← 仅当有可说时     │
└─────────────────────────────┘
```

### 11.4 焦距与现有质量三角的对应关系

每个透镜文件的"质量三角"是焦距在该体裁中的落地形态。三角的角与焦距之间存在映射关系——这个映射**不是一对一**的，一个三角的角可能涉及多个焦距。集成时需要在焦距章节中声明这个映射，确保分析协议执行时焦距扫描覆盖了三角检查所需的数据。

**诗性透镜 (poetic.md) — 诗性铁三角**：

| 三角的角 | 主焦距 | 辅助焦距 | 扫描时注意 |
|---------|--------|---------|----------|
| 意象落地 | 语义层 | — | 意象是否在后续文本中被展开/变形/收束——这是语义链追踪的核心操作 |
| 意象间张力 | 语义层 | 语言层 | 两个意象并置时——语言层的句法连接方式（断裂/叠加/呼应）是张力来源的线索 |
| 节奏呼吸 | 语言层 | 结构层 | 句式整齐或断裂——语言层扫描句长分布和修辞模式，结构层检查断裂是否形成有意义的节奏模式 |

**叙事透镜 (narrative.md) — 叙事铁三角**：

| 三角的角 | 主焦距 | 辅助焦距 | 扫描时注意 |
|---------|--------|---------|----------|
| 因果功能 | 结构层 | 语义层 | 场景之间的因果链——结构层追踪段落功能序列，语义层检查"从 A 状态变为 B 状态"的语义转变 |
| 人物真实 | 情感层 | 语用层 | 人物的内心驱力——情感层追踪人物行动的情感一致性，语用层检查叙述者是否在替人物"解释"动机 |
| 读者张力 | 语用层 | 情感层 | 读者在等待/预测什么——语用层检查预设-兑现结构，情感层检查情感钩子的设置与收束 |

**论述透镜 (argument.md) — 论述质量三角**：

| 三角的角 | 主焦距 | 辅助焦距 | 扫描时注意 |
|---------|--------|---------|----------|
| 论点锚定 | 结构层 | 语义层 | 核心主张是否可被提取——结构层扫描论点位置和段落功能，语义层检查关键概念定义的稳定性 |
| 推理链完整 | 结构层 | 批判层 | "因此"的每一步是否成立——结构层追踪推理步骤，批判层检查隐含前提是否填补了推理缺口 |
| 反证诚实 | 批判层 | 语用层 | 是否面对最强的反方观点——批判层识别未出现的驳论位，语用层检查说服策略是否回避了关键反方 |

**技术透镜 (technical.md) — 技术文本质量三角**：

| 三角的角 | 主焦距 | 辅助焦距 | 扫描时注意 |
|---------|--------|---------|----------|
| 定义精度 | 语义层 | 语言层 | 术语是否在首次出现时定义——语义层追踪术语一致性，语言层检查定义句的句法模式 |
| 信息架构 | 结构层 | 语义层 | 信息层级是否清晰——结构层判定架构类型，语义层检查各层级节点之间的语义关系 |
| 步骤完整 | 结构层 | 语用层 | 操作步骤缺前置条件——结构层追踪步骤序列，语用层检查读者能否执行每一步 |

**对话透镜 (dialogue.md) — 对话互动三角**：

| 三角的角 | 主焦距 | 辅助焦距 | 扫描时注意 |
|---------|--------|---------|----------|
| 话语权分布 | 语用层 | 语言层 | 话轮分配和权力关系——语用层分析参与者角色，语言层统计话轮长度/打断模式 |
| 话题控制 | 语用层 | 语义层 | 话题由谁定义和转换——语用层追踪话题开闭模式，语义层检查话题之间的语义连接 |
| 真实互动 | 情感层 | 语用层 | 双方是否在交换意义——情感层检查情感回应质量，语用层检查话轮之间的功能连接 |

**内省透镜 (personal.md) — 内省观察三角**：

| 三角的角 | 主焦距 | 辅助焦距 | 扫描时注意 |
|---------|--------|---------|----------|
| 自我观察焦点 | 情感层 | 语义层 | 观察的粒度和方向——情感层区分"命名"vs"呈现"，语义层追踪自我命名的稳定性 |
| 诚实度 | 批判层 | 情感层 | 自我解释 vs 自我观察——批判层识别解释框架的采用，情感层检查接近-回避模式 |
| 回避标记 | 批判层 | 语义层 | 接近敏感点后的撤退——批判层识别回避模式，语义层追踪话题转移的语义距离 |

**通用透镜 (general.md)**：无体裁特定三角。五个最低限度信号（长度与密度 / 人称与视角 / 重复与变化 / 连接方式 / 终点）各自映射到最近似的焦距——但通用透镜不声明优先级（全部 ★★），由文本实际信号决定启用哪些焦距。

### 11.5 集成操作步骤

对每个透镜文件执行以下操作：

**步骤 1：在体裁识别确认章节之后、X→Y→Z 映射表之前，插入焦距章节**

定位方式：找到 `## 本体裁 X→Y→Z 映射表` 这一行，在它**之前**插入焦距章节。如果文件中该行不存在，在 `## 体裁识别确认` 章节结束后的第一个空行处插入。

**步骤 2：填充优先级矩阵**

按 §11.6 集成清单中该透镜的核心/推荐/可选焦距，填入 ★★★/★★/★。对于 ★★★ 和 ★★ 的焦距，在"本体裁特化"列填入该体裁下的关注重点（1-2 句，从本规格对应焦距的"体裁适配"表中提取）。

**步骤 3：编写特化分析指令**

仅为 ★★★ 的核心焦距编写特化指令（★★ 焦距的特化已在优先级矩阵的"本体裁特化"列中给出；★ 焦距无需特化——默认跳过）。每条特化指令包含：
- 该焦距在该体裁下的分析入口调整（如果通用入口需要修改）
- 该焦距在该体裁下的额外约束边界（如果通用约束需要补充）

**步骤 4：编写"降低优先级时的处理"**

列出本透镜中优先级为 ★ 的焦距，说明在什么条件下触发（≥2 个强信号），以及跳过时的影响。

**步骤 5：验证三角-焦距映射**

检查 §11.4 中该透镜的三角-焦距映射表——确认质量三角的每个角都有对应的焦距覆盖。如果某个三角的角的主焦距优先级为 ★，这是**配置错误**——三角的核心检查逻辑依赖该焦距的数据，必须将优先级至少上调至 ★★。

## 附录 A：与铁律的接口

六维焦距分析全程受铁律约束。以下铁律与焦距分析直接相关：

| 铁律 | 焦距分析中的体现 |
|------|----------------|
| #2 不评价好坏 | 所有焦距描述效果，不评判质量——"被动语态集中在第二段"不是"第二段写得不好" |
| #5 每次开口必须带有文本诊断 | 每个焦距的输出必须从文本具体位置出发——"第三句的 X 导致了 Y" |
| #6 不问空问题 | 焦距分析中发现的问题必须通过文本中的证据来呈现——不问"你觉得呢？" |
| #7 指向文本不指向人格 | 批判层尤其注意——"文本隐含了 X 前提"而非"你持有 X 偏见" |
| #8 认知功能标签不宣示 | 深度分析触发（如 Ti 一致性堡垒）为内部分析框架，不向用户输出标签 |
