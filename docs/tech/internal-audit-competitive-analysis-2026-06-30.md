## 一、执行摘要

本次审查基于6家竞品的深度研究，以及text-lens产品在四个维度的内部审查。核心发现：

**第一，市场位势确认**。在 Claude Code Skill 生态中，文本分析/诊断品类完全空白——现有写作相关 Skill 全部是"辅助写作"（生成、润色、改写），没有任何一个是"反射分析"。text-lens 的"镜子式诊断"定位在 Skill 生态中是独一无二的。

**第二，X→Y→Z 诊断模型是真正的核心壁垒**。竞品全部停留在表层特征检测（语法/可读性/语气），而 text-lens 覆盖了从微观句法到隐含前提的完整分析谱系。特别是批判层（隐含假设、回避标记、框架效应）和情感层（情感空白、命名vs呈现的区分）是竞品完全不涉及的维度。

**第三，存在三类关键缺口**：
- **P0**：首次引导完全缺失——Web App 无示例、无引导文案
- **P0**：处理过程不透明——3-8秒等待期间无进度反馈
- **P1**：缺少量化描述层 + Z层方向句落地性弱于竞品的"一键修复"

**第四，内部架构维护负担**：六维焦距与质量三角是同一分析的两种表达，数字层在当前产品形态中实际是死代码。

## 三、竞品可学习点

### Grammarly
1. **Goals个性化机制**：用户预设写作目标（体裁/受众/目的）让透镜加载更精准
2. **渐进披露的交互设计**：基础建议自动显示/高级建议按需展开
3. **GrammarlyGO生成式能力**：一键改写/摘要/语气调整，降低修改门槛
4. **团队协作功能**：风格指南/品牌语气对企业市场有价值

### 秘塔写作猫
1. **场景化模板分类**：学术/公文/营销等子场景细分
2. **查重检测功能**：text-lens 可在技术/学术透镜中增加查重风险信号维度

### 火龙果写作
1. **论文降重功能**：切中中国学术写作刚需
2. **Freemium模式**：免费额度+付费会员，定价梯度成熟

### Hemingway Editor
1. **颜色编码的即时反馈**：视觉化标注比文字描述更直观
2. **极低学习成本**："粘贴即分析"零门槛
3. **聚焦单一价值观**："简洁=好"极易传播
4. **导出/发布集成**：支持直接发布到 WordPress/Medium

### QuillBot
1. **7种改写模式的UI设计**：模式切换而非理解NLP来控制输出
2. **并排对比视图**：原文与改写结果高亮差异呈现
3. **浏览器扩展分发**：嵌入用户现有工作流（Gmail/Docs/网页）
4. **Co-Writer多工具集成**：同一编辑器内集成改写/语法/摘要

### claude-writing-skills
1. **评分卡校准机制**：用 MAE/Spearman/分类准确度三指标量化评分质量
2. **"单点突破"迭代策略**：每轮只改一个维度，观察因果关系
3. **AI味道检测维度**："真人写作是有毛刺的"
4. **hard gates over polite suggestions**：强制 dry-run + 硬约束设计
5. **Claude Code Plugin marketplace 分发**

## 四、text-lens 核心优势（10项）

1. **X→Y→Z诊断模型**：覆盖从微观句法到隐含前提的完整分析谱系，竞品全部停留在表层
2. **7体裁透镜 × 6维焦距 × 6色信号**：分析自适应能力，诗性看意象张力，论述看推理链
3. **体裁自动预判路由**：零操作成本，优于Grammarly的Goals预设
4. **写作指纹跨文本追踪**：所有竞品都不具备的跨会话模式追踪能力
5. **11条铁律产品边界**：不评价、不替写、不命名用户的克制
6. **Skill多轮对话**：三级回退链，竞品全部是单次批处理
7. **渐进披露四层加载架构**：600t-3000t预算控制
8. **6色信号系统**：语义比Grammarly的颜色下划线更丰富
9. **品类开创者**：Claude Code Skill生态中文写作诊断完全空白
10. **铁律+边界约束系统**：确保交互不退化

## 六、架构建议

1. **统一焦距矩阵与质量三角**：将质量三角重构为"焦距在该体裁中的落地检查清单"
2. **建立全景矩阵文档**：单一体裁×焦距优先级表 + 透镜文件版本同步标记
3. **6色信号体裁感知细则**：各透镜焦距章节增加"体裁特定的6色信号调整"表
4. **Token预算自动路由**：≤100字→快速透视，100-500字→标准透视，>500字→深度透视
5. **精简数字层**：降级为"Web App L2引擎预留"脚注
6. **Web App 三层交互架构**：第1层粘贴即分析 → 第2层探索模式（追问/换角度/对比）→ 第3层书写模式（分屏编辑器实时反射）
7. **Edge Function 分阶段响应流**：体裁预判→透镜加载→诊断生成，每个阶段推送进度事件
8. **写作指纹服务端持久化**：Supabase fingerprints表，跨设备同步+激活进度可视化
9. **体裁插件机制**：lenses/目录YAML frontmatter + glob自动发现
10. **铁律自动化验证**：通过/失败示例对 + 冒烟测试 + devlog质量指标
