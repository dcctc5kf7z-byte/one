# 计数器与阈值集中管理

> **v5.0.1 作用域**：本文档仅用于**交互式写作过程诊断**（文本 ≤50 字 + 用户明确表达写作困难时触发）。通用文本分析路径不加载此文件。

所有散落在各文件中的计数器、阈值、触发条件在此集中定义。

---

## 表1: 推阻计数器事件表

| 事件 | 计数器操作 | 原因 |
|-----|----------|------|
| 用户在同一位置绕第三圈 | +1 | 推进无效 |
| 用户说"你觉得怎么样" | +1 | 推回决策权 |
| 用户解释为什么写不下去（非写本身） | +1 | 元认知替代写作 |
| 用户说"不知道"且不接任何推进 | +1 | 主动拒绝推进 |
| AI判断失误被用户纠正 | +1 | 技能自身增加阻力 |
| 用户写了新内容（≥2句） | 归零 | 推进成功 |
| 用户采纳了诊断并行动 | 归零 | 推进成功 |
| 用户说"对"或"继续" | 归零 | 推进成功 |
| 用户主动提出新方向 | 归零 | 用户自己推进了 |
| 用户明确拒绝一个推进但给出理由 | 归零 | 拒绝是推进的一部分 |

## 表2: 推阻阈值动作表

| 计数器值 | 状态 | 动作 | 退出条件 |
|---------|------|------|---------|
| 0-2 | 正常 | 继续推 | — |
| 3 | 预警 | 推进 + 追加一句观察"你在绕" | 用户写了新内容 |
| 4-5 | 触发制高点 | 切换制高点视角，一语道破拖沓或逃避 | 用户承认 / 写了新内容 / 问"那现在怎么办" |
| 6+ | 最后防线 | "先写一句。不管是什么。写完了再说。" | 用户写了任意内容 |

不跨任务、不跨会话（同一任务中断后恢复时保留计数器值）。

## 表3: 各侧面独立阈值表

| 侧面 | 计数器 | 阈值 | 溢出动作 |
|-----|--------|------|---------|
| 同路人 | 否定词（"不是/并非"） | ≥3 | "你否定了三次——你真正想说的是什么？" |
| 同路人 | 悬置词（"或许/也许"） | ≥5 | "先落一个。哪个方向你最有把握？" |
| 引爆器 | 隐喻跳跃次数 | ≥4 | "回到第一个意象。它还没被用完。" |
| 追问者 | 同句/同意象反复出现 | ≥3 | "不要打磨这一句了。下一段。" |
| 全部侧面 | 推阻计数器 | 见表2 | 见表2 |
