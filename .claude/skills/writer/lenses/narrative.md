# 叙事透镜 — 叙事/故事文本分析

> 适用于：小说段落、短篇故事、叙事散文、场景描写、人物故事、narrative prose、fiction。
> 不适用于：诗性叙事（→意象透镜或双透镜）、新闻报道（→信息透镜）。

## 体裁识别确认

加载本透镜后，先确认体裁假设：
- 是否包含人物/行动者 + 动作 + 场景？→ 确认
- 是否有时间推进或因果链？→ 确认
- "然后呢？"是否是一个有意义的问题？→ 确认
- 若三项中 ≤1 项成立 → 降级为通用透镜

## 本体裁 X→Y→Z 映射表

| 层 | 叙事文本的问题 | 诊断维度 |
|----|-------------|---------|
| **X — 表面效果** | 读者在这个场景里读到了什么？人物在做什么？场景在发生什么？ | 场景要素识别 + 叙事节奏 |
| **Y — 结构动力学** | 场景和场景之间的因果链是否成立？人物的动作来自内心驱力还是情节需要？读者的张力是否被维持？ | 铁三角扫描（因果功能 / 人物真实 / 读者张力） |
| **Z — 揭示与方向** | 哪个角松了？往哪推？ | 从最松的角给出推进方向 |

## 铁三角判定表

| 铁三角角 | 松动信号 | 诊断问题 | 推进方向 |
|---------|---------|---------|---------|
| **因果功能** | 读完后不知道"所以呢？" | "这个场景改变了什么？如果什么都没改变——它凭什么在这里？" | 锚定因果链 |
| **人物真实** | 人物做了动作但读者不信 | "这是他在此刻内心会做的事，还是你（作者）需要他做的事？" | 锚定内心驱力 |
| **读者张力** | 文本在叙述但读者没被钩住 | "读者此刻在等待什么？你给了他们什么？他们还等吗？" | 锚定预测/回忆 |

三角全紧 → 不碰，推下一段。

人物真实角深化诊断 → `reference/archetypes.md` 原型四层（可选加载）。

## 分析协议

### 第一步：场景要素采集
- 谁在这个场景里？在做什么？
- 场景的起点和终点——什么东西从 A 状态变成了 B 状态？
- 这个场景和上一个场景的因果接口是什么？

### 第二步：铁三角扫描
- 逐角检查——每角一句话评估（✓/✗ + 判断）
- 确定最松的角

### 第三步：推进方向
- 从最松的角给出一个具体的推进问题
- 不从"你想让读者感受到什么"出发——从人物内心往外推

**推动方向：由内向外**
```
人物内心发生了什么变化？（起点）
  → 这个变化如何被因果链承载？（连接）
    → 这个因果链如何被叙事操作呈现？（落地）
      → 这在读者身上产生什么认知效果？（最后才问）
```

## 禁止项

| 禁止 | 原因 |
|-----|------|
| 问"这个场景里有什么物件" | 文本里已有——不问已知信息 |
| 问"光线是什么颜色" | 感官细节用户自己会填充 |
| 三角都紧时没事找事 | 推进，不骚扰 |
| 说"这段写得很有画面感" | 不是评委 |
| 从读者感受往内设计 | 永远从人物内心往外推 |

## 输出调整

- 铁三角扫描结果在【Y — 结构成因】中自然呈现——不列标签，用叙事语言表达
- 【特征】：可选。指出叙事视角（第一/第三/全知/限知）、时态、场景密度
- 英文叙事分析维度（内部参考·输出时用目标语言描述现象）：时态一致性、视角稳定性、展示与告知的平衡

- 铁三角扫描无法定位问题 → `reference/narrative-theory.md`
- 人物原型/角色深度问题 → `reference/archetypes.md`

## 焦距优先级与动作句方向库

> 动作句 = 颜色手势（[G-5 §3](../../../docs/tech/action-sentence-templates.md#3-六色信号--六种动作句型)）+ 焦距证据（[G-5 §4](../../../docs/tech/action-sentence-templates.md#4-焦距--动作词汇映射)）+ 体裁方向（本节）。铁律 #9（推≠替写）、#10（动作句优先）约束所有动作句。

**焦距优先级**：情感 ★★★ / 结构 ★★★ / 语言 ★★ / 语义 ★★ / 语用 ★★ / 批判 ★

### 叙事方向库

| 方向 | 动作句尾句 |
|------|----------|
| 锚定因果链 | "从这一幕到下一幕——什么东西必须改变？" |
| 锚定人物驱力 | "他在此刻内心发生了什么——不是你需要他做什么" |
| 锚定读者张力 | "读者此刻在等什么？你给了他们什么？他们还等吗？" |
| 场景功能 | "这个场景在整条因果链上的位置是什么？" |
| 叙事节奏 | "这一段的节奏是场景还是概括？要不要换一口气？" |

### 结构层动作句（★★★ 核心焦距）

```
因果链缺环（胭脂红）：
"这里停下来——从{P1}的'{W1}'到{P2}的'{W2}'，中间缺了一步。
 读者知道发生了什么——但不知道为什么会发生。
 那个'为什么'——你的人物的内心知道吗？"

场景未改变状态（钢蓝）：
"注意——这个场景从开头到结尾，什么东西从A状态变成了B状态？
 如果什么都没变——这个场景凭什么在这里？
 不是因为'没东西发生'——是因为改变了的东西你还没写出来。"

因果链完整（钢蓝）：
"因果链是紧的——从'{W1}'到'{W2}'每一步都有。不碰现有结构。
 下一个场景：{D}"
```

### 情感层动作句（★★★ 核心焦距）

```
情感空白（胭脂红）：
"这里停下来——'{W}'发生了，然后下一句直接跳到了'{W2}'。
 读者在那个门口等着一个人的反应——但文本没给。
 你的人物的内心——在这一刻发生了什么？"

人物驱力不在场（堇紫）：
"想一想——文本下面还有一层。'{人物}'做了{动作}——但为什么做？
 是他在此刻内心会做的事——还是你（作者）需要他做的事？
 如果是后者——你不需要回答我。你只需要知道这个差别。"
```

### 推荐焦距简化模板

```
语言层·句式变化：
"全篇{N}句，{动作句}占{X}%，{描写句}占{Y}%。
 读者在{动作密集处}被推着走——在{描写密集处}被拉着停。
 这个推拉节奏——你感觉到了吗？"

语义层·主题一致性：
"'{W}'在{P1}{P2}{P3}出现了三次——每次在做什么？
 第一次被引入，第二次被{变形/对照/深化}，第三次——还没发生。"

语用层·读者张力：
"读者在{P}之后开始等——等了{N}段还没等到。
 那个等待——是你故意拉着的吗？还是你忘了你放了钩子？"
```
