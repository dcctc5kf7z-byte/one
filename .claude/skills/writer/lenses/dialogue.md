# 交互透镜 — 对话/交流文本分析

> 适用于：对话记录、采访稿、聊天记录、剧本对白、邮件往来、conversation transcripts、dialogue、interview notes。
> 不适用于：叙事中的对话段落（→叙事透镜——对话服务于故事因果链）。

## 体裁识别确认

加载本透镜后，先确认体裁假设：
- 是否有 ≥2 个参与者？→ 确认
- 是否有话轮转换（turn-taking）结构？→ 确认
- 文本的核心信息是否在交互中产生（而非在独白中）？→ 确认
- 若三项中 ≤1 项成立 → 降级为通用透镜

## 本体裁 X→Y→Z 映射表

| 层 | 对话文本的问题 | 诊断维度 |
|----|-------------|---------|
| **X — 表面效果** | 谁在说话？谁在听？话轮如何分配？说了什么？ | 话轮统计 / 话题流 / 参与者角色 |
| **Y — 结构动力学** | 对话的权力关系是什么？谁说得多谁说得少？谁在定义话题谁在跟随？沉默在谁那一边？ | 权力结构 / 话题控制 / 回避模式 / 未说出口的东西 |
| **Z — 揭示与方向** | 这个对话暴露了什么互动模式？有什么该说但没说的话？ | 指向一个未被接住的话头或一个结构性的回避 |

### 对话文本互动三角

| 角 | 松动信号 | 诊断问题 |
|----|---------|---------|
| **话语权分布** | 一方占据 ≥70% 的话轮或字数——对话变成独白 | "在这个对话里，A 在说，B 在听——或者说 B 在场。B 的声音是在回应还是在填充？" |
| **话题控制** | 一方反复将话题拉回自己的方向——对方的开启被忽略或截断 | "A 第三次提起 X 的时候——B 接了吗？还是 B 每一次都回到了 Y？" |
| **真实互动** | 双方在交换符号但不在交换意义——客套/回避/各说各话 | "他们在对话——但他们在互相听见吗？A 的回应和 B 的上一句话之间，有没有真实的连接？" |

三角全紧 → 互动是真实的、平衡的、有连接的。反射互动模式，指向可探索的未竟话题。

## 分析协议

### 第一步：话轮结构扫描
- 话轮分布统计（每个参与者的发言次数和字数）
- 话轮转换模式：承接（接住上一个人的话题）、偏移（微调方向）、截断（换话题）、沉默（话轮中断后的空白）
- 对话节奏：快（短话轮快速交替）还是慢（长话轮，回应有延迟）？

### 第二步：权力与关系分析
- 谁在定义话题？谁在跟随？
- 谁的开启被接住了？谁的被忽略了？
- 情感劳动是谁在做？（谁在调节气氛、谁在确认对方感受、谁在维持对话进行？）
- 未说的话：哪个话题被提起来然后被绕开了？哪个问题被问了但没被回答？

### 第三步：互动模式反射
- 这个对话的最显著互动模式是什么？（互相建设？各说各话？一人主讲一人附从？暗流涌动的冲突？）
- 如果这个模式持续下去——什么话会永远说不出来？

## 禁止项

| 禁止 | 原因 |
|-----|------|
| 替对话中的任何一方站队 | 镜子不选边——只反射互动结构 |
| 揣测参与者的心理动机（"他之所以这么说是因为……"） | 文本里没有的东西不说——只分析可观察的互动模式 |
| 把"对话不流畅"当作问题 | 不流畅的对话可能是最有张力的对话——不假设流畅=好 |
| 忽略文化差异 | 话轮打断在有些文化中是参与，在另一些中是侵犯——不做跨文化假设 |

## 输出调整

- 【特征】：必出。话轮分布、话题流、互动模式类型
- 剧本/对白：注意 subtext——角色说的话和角色真正在"说"的东西之间的差距
- 采访稿：注意访问者的提问策略——开放/封闭/引导/中立——和受访者的回应模式
- 聊天记录：注意媒介特性——emoji、回复延迟、消息长度——这些都是互动信号
- 英文对话分析维度（内部参考·输出时用目标语言描述现象）：礼貌策略、模糊限制语、反馈通道等跨文化互动特征

## 深度分析触发

- 共识漂移（无人主动发起，都在等待对方定义话题）→ `reference/cognitive-functions.md`（Fe 共识漂移）
- 权力关系深度分析 → `reference/philosophical-lens.md`
- 对话中的叙事线 → 可并行加载叙事透镜

## 焦距优先级与动作句方向库

> 动作句 = 颜色手势（[G-5 §3](../../../docs/tech/action-sentence-templates.md#3-六色信号--六种动作句型)）+ 焦距证据（[G-5 §4](../../../docs/tech/action-sentence-templates.md#4-焦距--动作词汇映射)）+ 体裁方向（本节）。铁律 #9（推≠替写）、#10（动作句优先）约束所有动作句。

**焦距优先级**：情感 ★★★ / 语用 ★★★ / 语言 ★★ / 语义 ★★ / 批判 ★★ / 结构 ★

### 对话方向库

| 方向 | 动作句尾句 |
|------|----------|
| 接住未被接住的话 | "那句话还在空中——谁来接？" |
| 平衡话语权 | "{角色}的声音——在这个对话里还有空间吗？" |
| 觉察回避 | "这个话题被提了{N}次，绕了{N}次——它在怕什么？" |
| 检验真实互动 | "他们在交换符号——还是在交换意义？" |
| 面对沉默 | "那个沉默——是谁的？它在说什么？" |

### 情感层动作句（★★★ 核心焦距）

```
情感回应被忽略（胭脂红）：
"这里停下来——{角色A}说了'{W}'，{角色B}回应了'{W2}'。
 B回应了话题——但没有回应A的情感。
 A在'{W}'里的那层感受——没有被接住。"

情感劳动分配（琥珀黄）：
"看见了吗——每一次气氛紧张的时候，都是{角色A}在调节。
 {角色B}的感受被照顾了——{角色A}的呢？
 情感劳动在这个对话里——不是分配的，是默认归了一方。"
```

### 语用层动作句（★★★ 核心焦距）

```
话题被截断（胭脂红）：
"这里停下来——{角色A}第三次提起'{W}'。
 每一次，{角色B}都把话题拉回了'{W2}'。
 A的'{W}'——在这个对话里是不被允许的。"

话语权失衡（琥珀黄）：
"{角色A}占了{N}%的话轮——{角色B}在听，或者说在场。
 这不是对话——这是独白。
 但{B}的沉默——本身在说话。它在说什么？"

未说出口的话（钢蓝）：
"注意——'{W}'被提起来了，然后被绕开了。
 这个话题在这个对话里——是存在的，但不被允许完成。
 如果你（作者）知道它是什么——它是什么？"
```

### 推荐焦距简化模板

```
语言层·话轮模式：
"A的平均话轮长度是B的{N}倍。B的回应平均{M}字。
 B是在回应——还是在填充沉默？"

批判层·未言明的预设：
"想一想——这个对话进行下去的前提是双方假装'{W}'是共识。
 如果有一方不再假装——这个对话会变成什么样？"
```
