# 意象透镜 — 诗性/意象文本分析

> 适用于：诗、散文诗、意象密集段落、古典诗词、haiku、lyrical prose、experimental poetry。
> 不适用于：叙事诗（→叙事透镜）、说理诗（→逻辑透镜或双透镜）。

## 体裁识别确认

加载本透镜后，先确认体裁假设：
- 意象是否密集？（≥3 个独立意象 / 100 字）→ 确认
- 逻辑连接词是否稀疏？（然而/因此/但是 等 ≤1 个 / 100 字）→ 确认
- 节奏/韵律是否优先于论述逻辑？→ 确认
- 若三项中 ≤1 项成立 → 降级为通用透镜

## 本体裁 X→Y→Z 映射表

| 层 | 诗性文本的问题 | 诊断维度 |
|----|-------------|---------|
| **X — 表面效果** | 读者读到了哪些意象？意象之间形成了什么关系（呼应/对峙/断裂/叠加）？ | 意象识别 + 意象间关系 |
| **Y — 结构动力学** | 意象之间的张力来自哪里？是相似性（隐喻链）还是差异性（意象跳跃）？跳跃有没有给读者足够的桥？ | 意象间张力 / 隐喻链完整度 / 跳跃跨度的可追踪性 |
| **Z — 揭示与方向** | 这个意象结构暴露了什么未完成的潜力？哪个意象还没被用完？ | 指向一个未完成的意象——让它做一件事 |

### 诗性文本铁三角（替代叙事铁三角）

| 角 | 松动信号 | 诊断问题 |
|----|---------|---------|
| **意象落地** | 意象被引入但未展开——它出现了但什么都没做 | "这个意象在这里引入了——它改变了什么？如果它只是'被提到'，它还没开始工作。" |
| **意象间张力** | 两个意象放在一起但没有产生第三物——它们只是并列 | "A 和 B 放在一起——它们之间生出了什么？还是只是站在一起？" |
| **节奏呼吸** | 句式整齐但无断裂——读者在预期中滑行，没有被绊住 | "这里的节奏是顺畅的——顺畅到读者可以不用停下来。你需要一个断裂吗？" |

三角全紧 → 这个意象结构是成立的。指下一个方向，不碰现结构。

## 分析协议

### 第一步：意象扫描
- 列出文本中出现的独立意象（名词或名词短语，承载感官/情感重量）
- 标记意象之间的关系类型：呼应（相似性）、对峙（对立/矛盾）、断裂（跳跃无桥）、叠加（层层累积）
- 英文诗分析维度（内部参考·输出时用目标语言描述现象）：声韵模式（头韵/半谐音/重音模式）、换行功能

### 第二步：意象动力学
- 哪个意象是核心（出现最早/最密集/其他意象围绕它组织）？
- 意象序列有没有方向——从什么到什么？
- 跳跃间距是否可追踪？（跳跃太大→读者迷失；跳跃太小→没有张力）

### 第三步：未完成指向
- 哪个意象被引入了但还没被"用完"——它出现了但还没做任何事
- 哪个意象链的最后一环缺失——它指向了一个方向但没到达

## 禁止项

| 禁止 | 原因 |
|-----|------|
| 翻译意象（"这个意象的意思是……"） | 意象不需要翻译——翻译杀死意象 |
| 纠正语法 | 故意错误是诗性创作的方法 |
| 把意象拉回"合理" | 诗不需要合理——需要意象落地 |
| 解释隐喻（"A 象征着 B"） | 隐喻的力量在不确定性中——解释拿走力量 |
| 用叙事逻辑评判诗性结构 | 诗不是故事——因果关系不适用 |

## 输出调整

- 【特征】字段必出——诗性文本的显著特征（意象密度、韵律模式、隐喻类型）是指向性的重要部分
- 不说"这首诗写得好"——说"这个意象在第三行完成了它的动作"
- 不预设"古典诗"或"现代诗"的评判标准——只描述意象在读者意识中的效果
- 英文诗：保持术语的跨文化适用性——enjambment、caesura、alliteration 等术语只在必要时用，优先用可感知的描述

## 深度分析触发

- 同一意象反复出现但无推进 → `reference/cognitive-functions.md`（Ni 聚合陷阱）
- 意象跳跃 ≥4 次且无核心 → 触发"回到第一个意象"协议
- 神话/典故引用密集 → 可选加载 `reference/archetypes.md`

## 焦距优先级与动作句方向库

> 动作句 = 颜色手势（[G-5 §3](../../../docs/tech/action-sentence-templates.md#3-六色信号--六种动作句型)）+ 焦距证据（[G-5 §4](../../../docs/tech/action-sentence-templates.md#4-焦距--动作词汇映射)）+ 体裁方向（本节）。颜色信号定义见 [Hermes 6 色信号](../reference/hermes-color-signals.md)。铁律 #9（推≠替写）、#10（动作句优先）约束所有动作句。

**焦距优先级**：语义 ★★★ / 语言 ★★★ / 情感 ★★ / 批判 ★★ / 结构 ★ / 语用 ★

> 焦距定义与分析协议见 [G-1 六维焦距引擎](../../../docs/tech/focal-engine-spec.md)。

**为什么这个优先级？**
- 诗性文本的核心是意象之间的关系（语义★★★）和语言的节奏/密度（语言★★★）——意象不落地、节奏不呼吸，诗不成立
- 情感通过意象呈现而非直接说出（情感★★）；批判层看诗选择呈现/省略的世界（批判★★）
- 结构层的因果逻辑在诗中不适用——意象结构的"断裂"可能是故意的方法（结构★）

### 诗性方向库

| 方向 | 动作句尾句 |
|------|----------|
| 让意象落地 | "让它做一件事——不是被看到，是去触碰" |
| 制造意象间张力 | "让它们互相质问——不是并列，是互相改变" |
| 收束悬空意象 | "它还在悬着——你打算让它落吗？落在哪里？" |
| 节奏断裂 | "这个节奏顺畅到读者可以不停下来——你需要一个断裂吗？" |
| 意象展开 | "'{W}'还没被用完——它还有第二件事可以做" |

### 语义层动作句（★★★ 核心焦距）

```
意象未落地（钢蓝）：
"注意——'{W}'在{P}被引入了。它出现了——但它什么都没做。
 这个意象还没落地。它可以往{D}走——不是解释它，是让它做一个动作。"

意象间无张力（钢蓝）：
"'{W1}'和'{W2}'在{P}放在了一起——但它们只是站在一起。
 两个意象之间还没有产生第三物。它们可以互相{D}——不是并列，是互相改变。"

意象链断裂（琥珀黄）：
"看见了吗——从{P1}的'{W1}'到{P2}的'{W2}'，中间有一个跳跃。
 读者在这个跳跃里需要自己找桥。那个桥——你在写的时候看到了吗？"
```

### 语言层动作句（★★★ 核心焦距）

```
节奏需要断裂（胭脂红）：
"这里停下来——从{P1}到{P2}，句式一直整齐。读者的呼吸被固定在一个节奏里。
 到{P3}突然断了——只有四个字。那个断开让读者停了一下。
 这个断裂——你还需要更多吗？还是这一个就够了？"

句法模式重复（琥珀黄）：
"看见了吗——连续{N}句以'{W}'开头。读者的注意力一直被锁在同一个位置。
 这不是偶然——但你有没有给读者一个换气的机会？"
```

### 推荐焦距简化模板

```
情感回避/空白（堇紫）：
"想一想——在{P}，文本靠近了一个情感位置，然后转向了。
 那个被绕过的东西——还在那里。"

诗的选择性（堇紫）：
"想一想——这首诗选择呈现了{W1}，省略了{W2}。
 那个边界——呈现与省略之间——它在说什么？"
```
