# 意象透镜 — 诗性/意象文本分析

> 适用于：诗、散文诗、意象密集段落、古典诗词、haiku、lyrical prose、experimental poetry。
> 不适用于：叙事诗（→叙事透镜）、说理诗（→逻辑透镜或双透镜）。

## 体裁识别确认

加载本透镜后，先确认体裁假设：
- 意象是否密集？（≥3 个独立意象 / 100 字）→ 确认
- 逻辑连接词是否稀疏？（然而/因此/但是 等 ≤1 个 / 100 字）→ 确认
- 节奏/韵律是否优先于论述逻辑？→ 确认
- 若三项中 ≤1 项成立 → 降级为通用透镜

## 本体裁 X→Y→Z 映射表

| 层 | 诗性文本的问题 | 诊断维度 |
|----|-------------|---------|
| **X — 表面效果** | 读者读到了哪些意象？意象之间形成了什么关系（呼应/对峙/断裂/叠加）？ | 意象识别 + 意象间关系 |
| **Y — 结构动力学** | 意象之间的张力来自哪里？是相似性（隐喻链）还是差异性（意象跳跃）？跳跃有没有给读者足够的桥？ | 意象间张力 / 隐喻链完整度 / 跳跃跨度的可追踪性 |
| **Z — 揭示与方向** | 这个意象结构暴露了什么未完成的潜力？哪个意象还没被用完？ | 指向一个未完成的意象——让它做一件事 |

### 诗性文本铁三角（替代叙事铁三角）

| 角 | 松动信号 | 诊断问题 |
|----|---------|---------|
| **意象落地** | 意象被引入但未展开——它出现了但什么都没做 | "这个意象在这里引入了——它改变了什么？如果它只是'被提到'，它还没开始工作。" |
| **意象间张力** | 两个意象放在一起但没有产生第三物——它们只是并列 | "A 和 B 放在一起——它们之间生出了什么？还是只是站在一起？" |
| **节奏呼吸** | 句式整齐但无断裂——读者在预期中滑行，没有被绊住 | "这里的节奏是顺畅的——顺畅到读者可以不用停下来。你需要一个断裂吗？" |

三角全紧 → 这个意象结构是成立的。指下一个方向，不碰现结构。

## 分析协议

### 第一步：意象扫描
- 列出文本中出现的独立意象（名词或名词短语，承载感官/情感重量）
- 标记意象之间的关系类型：呼应（相似性）、对峙（对立/矛盾）、断裂（跳跃无桥）、叠加（层层累积）
- 英文诗分析维度（内部参考·输出时用目标语言描述现象）：声韵模式（头韵/半谐音/重音模式）、换行功能

### 第二步：意象动力学
- 哪个意象是核心（出现最早/最密集/其他意象围绕它组织）？
- 意象序列有没有方向——从什么到什么？
- 跳跃间距是否可追踪？（跳跃太大→读者迷失；跳跃太小→没有张力）

### 第三步：未完成指向
- 哪个意象被引入了但还没被"用完"——它出现了但还没做任何事
- 哪个意象链的最后一环缺失——它指向了一个方向但没到达

## 禁止项

| 禁止 | 原因 |
|-----|------|
| 翻译意象（"这个意象的意思是……"） | 意象不需要翻译——翻译杀死意象 |
| 纠正语法 | 故意错误是诗性创作的方法 |
| 把意象拉回"合理" | 诗不需要合理——需要意象落地 |
| 解释隐喻（"A 象征着 B"） | 隐喻的力量在不确定性中——解释拿走力量 |
| 用叙事逻辑评判诗性结构 | 诗不是故事——因果关系不适用 |

## 输出调整

- 【特征】字段必出——诗性文本的显著特征（意象密度、韵律模式、隐喻类型）是指向性的重要部分
- 不说"这首诗写得好"——说"这个意象在第三行完成了它的动作"
- 不预设"古典诗"或"现代诗"的评判标准——只描述意象在读者意识中的效果
- 英文诗：保持术语的跨文化适用性——enjambment、caesura、alliteration 等术语只在必要时用，优先用可感知的描述

## 深度分析触发

- 同一意象反复出现但无推进 → `reference/cognitive-functions.md`（Ni 聚合陷阱）
- 意象跳跃 ≥4 次且无核心 → 触发"回到第一个意象"协议
- 神话/典故引用密集 → 可选加载 `reference/archetypes.md`

## 例句

> "第三行的'镜光浮影'之后——你给了'风飘渺'和'落井石'，但读者还没看到镜光里的影子是什么。那个影子还没被用完。"
>
> "'梅占点夕'和'兰因絮果'之间——一个是侵占，一个是因果。它们不是并列的。这个张力你在哪里收？"
