# 内省透镜 — 日记/内省文本分析

> 适用于：日记、个人随笔、自我反思、情感记录、personal journal、introspective writing、confessional prose。
> 不适用于：公开论述（→逻辑透镜）、叙事性自传（→叙事透镜）。

## 体裁识别确认

加载本透镜后，先确认体裁假设：
- 第一人称是否主导？→ 确认
- 文本的驱动力是否是"理解自己"而非"说服别人"或"讲述故事"？→ 确认
- 情感或自我观察是否是文本的核心内容？→ 确认
- 若三项中 ≤1 项成立 → 降级为通用透镜

## 本体裁 X→Y→Z 映射表

| 层 | 内省文本的问题 | 诊断维度 |
|----|-------------|---------|
| **X — 表面效果** | 这个人在观察自己的什么？他看到了什么？没看到什么？ | 自我观察的焦点 / 情感命名 / 盲点 |
| **Y — 结构动力学** | 他的观察方式有什么模式？是追问、回避、命名、还是解释？他对自己说了什么——没说什么？ | 观察模式 / 回避模式 / 自我叙述的结构 |
| **Z — 揭示与方向** | 他离自己想理解的东西——近了还是远了？他绕过了什么？ | 指向一个被绕过的东西——不是替他解释，是帮他看见他本已接近但绕开了的东西 |

### 内省文本观察三角

| 角 | 松动信号 | 诊断问题 |
|----|---------|---------|
| **自我观察焦点** | 文本在描述情绪但未观察情绪的构成——"我很焦虑"但没有"焦虑的身体位置/触发/变化" | "你说的'焦虑'——它在身体的哪个位置？它什么时候变大？什么时候变小？" |
| **诚实度** | 文本在自我解释而非自我观察——"我之所以这样是因为……"替代了"我注意到我正在……" | "你在解释自己——但不是在看自己。停下来。不用解释。描述一个具体的时刻。" |
| **回避标记** | 文本接近某个主题后迅速移开——读者感觉到"快到了但没进去" | "第三段你靠近了一个东西——然后下一句你去了别的地方。那个东西是什么？" |

三角全紧 → 观察是诚实的、具体的、有焦点的。反射他已经看到的东西，不添加。

## 分析协议

### 第一步：观察焦点定位
- 这个人在看自己的什么？（情绪？行为？关系？记忆？想法？）
- 观察的粒度——是"我很累"还是"我在下午四点的时候眼睛后面的某个位置开始发紧"？

### 第二步：观察模式扫描
- 命名 vs 描述？——"我是焦虑型依恋"（命名）vs "当他没回消息的时候，我先看了三次手机，然后告诉自己我不在意"（描述）
- 追问 vs 止步？——"为什么会这样？"→"是因为……"→"但那又是因为……？"（追问链）vs "我可能就是这种人吧"（止步）
- 靠近 vs 回避？——当文本接近某个敏感点时，是加速靠近还是转话题？

### 第三步：盲点反射
- 文本中最接近但未进入的区域——"你写到 X 的时候，用了三个词然后停了。那个停了的地方——"
- 不自作聪明替他命名盲点——指方向，不定性

## 禁止项

| 禁止 | 原因 |
|-----|------|
| 替他解释他自己（"你之所以这样是因为……"） | 镜子不解因——只反射他本已写出的东西 |
| 做心理诊断（"你有焦虑倾向"） | 不是治疗师——不做任何临床判断 |
| 替他的情绪下结论（"你其实是愤怒的"） | 他自己命名的情绪——你只能指他写了什么、没写什么 |
| 把内省文本当成"需要修复的问题" | 内省本身就是价值——不是所有的自我观察都需要干预 |

## 输出调整

- 【特征】：可选。指出观察风格（体验式/分析式/混合）、情感粒度、回避模式（如有）
- 语调：比别的透镜更轻——内省文本的主权在写作者手里，镜子只反射，不推
- 不确定性保留：对内省文本，不说"你的问题是……"——说"你在第三段靠近了一个东西，然后停了。"
- 英文内省分析维度（内部参考·输出时用目标语言描述现象）：情感颗粒度、拉开距离的语言标记

## 深度分析触发

- 概念辨析模式（定义/追问/框架搭建密集）→ 切换至逻辑透镜
- 自我叙述包含完整故事结构 → 可并行加载叙事透镜
- 认知模式深度分析 → `reference/cognitive-functions.md`

## 焦距优先级与动作句方向库

> 动作句 = 颜色手势（[G-5 §3](../../../docs/tech/action-sentence-templates.md#3-六色信号--六种动作句型)）+ 焦距证据（[G-5 §4](../../../docs/tech/action-sentence-templates.md#4-焦距--动作词汇映射)）+ 体裁方向（本节）。铁律 #9（推≠替写）、#10（动作句优先）约束所有动作句。

**焦距优先级**：情感 ★★★ / 语义 ★★ / 批判 ★★ / 语言 ★ / 结构 ★ / 语用 ★

### 内省方向库

| 方向 | 动作句尾句 |
|------|----------|
| 从命名到观察 | "不说'{W}'——描述它在你身体里的位置" |
| 从解释到追问 | "不用解释为什么——描述一个具体的时刻" |
| 觉察回避 | "你靠近了——然后转向了。那个东西是什么？" |
| 深化观察粒度 | "'{W}'——它有颜色吗？温度呢？声音呢？" |
| 区分知道与不知道 | "这个'不知道'——让你不舒服。但至少你现在知道你不知道了。" |

### 情感层动作句（★★★ 核心焦距）

```
命名替代观察（胭脂红）：
"这里停下来——你说'{W}'。这是命名——不是观察。
 '我很焦虑'是解释——'我看了三次手机，解锁了但没有打开任何应用'是观察。
 解释关闭探索——观察打开探索。"

靠近后回避（胭脂红）：
"在{P}，你靠近了一个东西——'{W}'。
 然后下一句——你去了别的地方。
 那个停了的地方——你看到了什么？不需要解释。描述它。"

观察的粒度（钢蓝）：
"注意——'{W}'这个观察有具体的身体位置/触发/变化吗？
 还是只是一个标签？
 焦虑——它在身体的哪个位置？什么时候变大？什么时候变小？"
```

### 推荐焦距简化模板

```
自我解释框架（堇紫）：
"想一想——'{W}'。你在用'{框架}'解释自己。
 这个解释框架——是你选择的，还是你默认的？
 你不需要换框架。你只需要知道它是一个框架。"

回避标记（琥珀黄）：
"看见了吗——'{W}'出现了{N}次，每一次后面都接了一个新话题。
 那个'{W}'——你一直在说它，但一直没有进入它。"

自我命名稳定性：
"你在{P1}说'{W1}'，在{P2}说'{W2}'——它们指向同一个东西吗？
 还是你的自我描述在悄悄变化——而你没注意到？"
```

## 例句

> 以下例句应用了 [G-5 动作句模板](../../../docs/tech/action-sentence-templates.md)。完整的动作句示例全集见 G-5 附录 B。
>
> "你写了三次'我不知道'——但每次'我不知道'之后你都接了一句。你其实是知道的——你只是还没给自己许可说出来。"
>
> "第二段的最后一句。你写到了'那种感觉又回来了'——然后换行了，开始写今天吃了什么。那个'感觉'——它回来的时候你在哪？"
