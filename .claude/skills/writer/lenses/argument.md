# 逻辑透镜 — 论述/观点文本分析

> 适用于：议论文、随笔论述、观点文章、评论、essay、argumentative prose、op-ed、哲学推演。
> 不适用于：纯信息罗列（→技术透镜）、情感驱动说服（→可能需叙事透镜辅助）。

## 体裁识别确认

加载本透镜后，先确认体裁假设：
- 是否有明确论点（显式或隐式）？→ 确认
- 是否有论证结构（原因/结果/反证/让步/总结）？→ 确认
- 文本的目的是否为"让读者接受一个观点或看到一种关系"？→ 确认
- 若三项中 ≤1 项成立 → 降级为通用透镜

## 本体裁 X→Y→Z 映射表

| 层 | 论述文本的问题 | 诊断维度 |
|----|-------------|---------|
| **X — 表面效果** | 读者被说服了吗？读者在哪个位置开始抵抗或滑开？ | 论点的清晰度 / 论证路径的可追踪性 / 反证是否被处理 |
| **Y — 结构动力学** | 论证链的哪个环节松了？是前提不成立、推理跳跃、还是结论超过前提？ | 推理链完整度 / 论据质量 / 反证处理 / "因此"的距离 |
| **Z — 揭示与方向** | 这个论证结构暴露了什么未检查的前提？哪个反证还没被面对？ | 指向一个未检查的前提或未面对的反证 |

### 论述文本质量三角

| 角 | 松动信号 | 诊断问题 |
|----|---------|---------|
| **论点锚定** | 读完不知道"作者到底主张什么" | "这篇文章的核心主张能缩成一句话吗？如果不能——它在主张什么？" |
| **推理链完整** | 从前提跳到结论中间缺了步骤——"A 所以 C" 但没有 B | "在 A 和 C 之间——中间那一步在哪？读者自己填了还是你给了？" |
| **反证诚实** | 只处理了弱的反方观点，或完全不提反方 | "最强的反方论点是什么？这个文本面对它了吗——还是绕过去了？" |

三角全紧 → 论证自洽。指下一个可展开的方向。

## 分析协议

### 第一步：论点提取
- 核心主张是什么？（显式或隐式——如无显式论点，从文本中重构）
- 论点是否有可证伪性？（"应该"类主张无法证伪，但可以检查其前提是否成立）

### 第二步：论证链追踪
- 从前提到结论，每一步之间的"因此"是否成立？
- 省略了哪些中间步骤？（读者被迫自己填充的步骤）
- 论据质量：事实？类比？权威？个人经验？每种论据的强度是否匹配主张的强度？

### 第三步：反证诚实度
- 文本是否承认了可能反对自己的最强论点？
- 如果处理了反证——处理方式是对抗还是收编？
- 如果没处理——那个沉默意味着什么？

## 禁止项

| 禁止 | 原因 |
|-----|------|
| 替用户站队（"你的观点是对的/错的"） | 镜子不判断立场——只诊断论证结构 |
| 用你自己知道的论据填补空缺 | 诊断的是文本自身的论证——不是你替它补充的 |
| 把"我不赞同"当作诊断 | 镜子不评判观点，只反射论证结构 |
| 替他简化概念 / 用标准术语替换私人词汇 | 他的词是他的推演工具 |

## 输出调整

- 【特征】字段：可选。指出论证风格（演绎/归纳/类比/混合）、论据偏好（数据/故事/权威/经验）
- 中文论述：注意"虽然……但是……"结构的平衡——让步是否真实还是走过场
- 英文论述分析维度（内部参考·输出时用目标语言描述现象）：修辞手段（反问/首语重复/情感-信誉-逻辑诉求平衡）
- 哲学推演型文本（概念辨析为主，论点不显）：切换至概念追踪模式——不找论点，追踪概念的演变

## 深度分析触发

- 否定螺旋（≥3 个"不是/并非"但没说"是什么"）→ 触发"停。说一遍它是什么。"
- 判断悬置（≥5 个"或许/也许"无落地）→ 触发"把可能拿掉。说一个确定的。"
- 术语闭环（自创术语形成封闭系统，未与外部连接）→ `reference/cognitive-functions.md`（Ti 一致性堡垒）
- 结构专制（论证结构绑架内容）→ `reference/cognitive-functions.md`（Te 结构专制）

## 焦距优先级与动作句方向库

> 动作句 = 颜色手势（[G-5 §3](../../../docs/tech/action-sentence-templates.md#3-六色信号--六种动作句型)）+ 焦距证据（[G-5 §4](../../../docs/tech/action-sentence-templates.md#4-焦距--动作词汇映射)）+ 体裁方向（本节）。铁律 #9（推≠替写）、#10（动作句优先）约束所有动作句。

**焦距优先级**：结构 ★★★ / 语用 ★★★ / 批判 ★★★ / 语义 ★★ / 语言 ★ / 情感 ★

### 论述方向库

| 方向 | 动作句尾句 |
|------|----------|
| 补推理步骤 | "在A和C之间——缺的那步B是什么？" |
| 检验前提 | "这个推理依赖了什么没被论证的前提？" |
| 面对反证 | "最强的反方观点——你面对它了吗？还是绕过去了？" |
| 论据匹配 | "主张的强度——论据撑得住吗？" |
| 概念稳定 | "同一个词在论证的不同阶段——含义变了吗？" |

### 结构层动作句（★★★ 核心焦距）

```
推理链跳跃（胭脂红）：
"这里停下来——从'{W1}'到'{W2}'，你跳了一步。
 前提和结论之间——中间那个'因此'没有被写出来。
 读者在这个位置被迫自己推理——但你是作者，推理是你的工作。"

论据不支撑主张（胭脂红）：
"你的主张是'{W}'——但你的论据是{个人经验/类比/权威/孤例}。
 主张的强度和论据的强度之间——有一个落差。
 主张要改变一群人的信念——论据能支撑这个重量吗？"

反证缺位（钢蓝）：
"注意——最强的反方论点'{W}'没有被面对。
 你处理了弱的那个——但强的那个还在。
 面对它——不是要你认输，是要你的论证更诚实。"
```

### 语用层动作句（★★★ 核心焦距）

```
读者预设错位（堇紫）：
"想一想——文本在{P}用了'{W}'这个词。它预设读者已经接受了{X}。
 不接受{X}的读者——还能被后面的论证触及吗？
 你不需要迎合所有人。但你需要知道你的门开在哪里。"

说服力衰减（琥珀黄）：
"看见了吗——从{P}开始，文本的语气从'{W1}'变成了'{W2}'。
 读者在那个位置从'被邀请'变成了'被告知'。
 语气提前关闭了对话——在论证还没完成之前。"
```

### 批判层动作句（★★★ 核心焦距）

```
隐含前提（堇紫）：
"想一想——文本下面还有一层。这个论证依赖了'{W}'这个前提。
 这个前提本身没有被论证——它被当作了自明的东西。
 你不需要论证一切。但你需要知道你在假设什么。"

价值预设（堇紫）：
"'显然'/'当然'/'毫无疑问'——这些词后面的东西，被当作了共识。
 对谁来说是共识？那个'谁'——你想过吗？"
```

### 推荐焦距简化模板

```
概念漂移（琥珀黄）：
"'{W}'在{P1}和{P2}——是同一个意思吗？
 如果这个词在论证中途悄悄变了含义——后面的推理还站得住吗？"
```

## 例句

> 以下例句应用了 [G-5 动作句模板](../../../docs/tech/action-sentence-templates.md)。完整的动作句示例全集见 G-5 附录 B。
>
> "你的核心主张在第三段落地了——'自由不是选择的自由，是选择之后的承担'。但从第二段的经验描述到第三段的这个结论之间——中间缺了一步：什么让你从这个具体的经验跳到了这个抽象的定义？"
>
> "你处理了三个反方观点——但都是弱的。最强的那个你一个字没提：如果'自由'本身是一个幻觉呢？"
