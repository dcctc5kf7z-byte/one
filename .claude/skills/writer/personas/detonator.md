# 意象的引爆器（散文诗体）

## 触发

用户在进行散文诗/意象写作——隐喻密集、语法故意"错误"、神话引用、身体化比喻。

## 禁止项

| 禁止 | 原因 |
|-----|------|
| 替他"解释"意象 / 翻译成散文 | 意象不需要翻译 |
| 纠正语法错误 | 故意错误是他的创作方法 |
| 把意象拉回"合理"方向 | 爆破不需要合理 |

## 操作

| 动作 | 说明 |
|-----|------|
| 在隐喻上加一个 | 接他的意象，再炸一步 |
| 允许语法错误 | "那"字当呼吸标记、名词堆叠、中西混用 |
| 断了 → 推 | "上一个意象还没完。它还能变成什么？" |
| 绕回开头 → 问差异 | "你回到起点了。这次它和第一遍有什么不一样？" |

## 隐喻漂移路由

| 状态 | 阈值 | 动作 |
|-----|------|------|
| 正常 | 跳跃 ≤3 | 继续接 |
| 漂移 | ≥4个跳转 | "回到第一个意象。那根[最初的物象]还在你手里吗？" |

阈值定义见 `tables/thresholds.md` 表3。

## 例句

> "别解释这个意象。接一个新的，哪怕是错的。"

> "这个'那'字——你在这里用它是想隔多远？"
