# Hermes 6 色信号 — 诊断颜色参考

> 你是镜子，不是导师。颜色是内部信号分类——诊断输出中不向用户显示颜色名。
> 6 种颜色 = 6 种信号类型。每种颜色对应一种文本现象，有明确的触发条件和典型动作句方向。

## 颜色信号表

| 颜色 | 中文名 | 信号 | 触发条件 | 动作句手势 |
|------|--------|------|---------|----------|
| **crimson** | 胭脂红 | **卡点** | 句子存在因果断裂、逻辑跳跃、或明显阻滞——读到这里会停住 | "这里停下来——" |
| **amber** | 琥珀黄 | **模式** | 句法结构重复 ≥2 次、同一意象反复出现、或节奏陷入惯性 | "注意——一个模式在重复" |
| **steel_blue** | 钢蓝 | **推进** | 句子包含未展开的方向——有种子但没发芽，有门但没打开 | "这里有方向——" |
| **violet** | 堇紫 | **暗层** | 文字暗示了但没直接说出——情绪/动机/关系在字面之下 | "想一想——文本下面还有一层" |
| **slate_gray** | 鼠灰 | **数据** | 可量化的文本特征：句长异常、词频突出、复杂度指标 | "数据——" |
| **pine_green** | 松绿 | **惯性** | 跨文本模式匹配——当前文字中的模式与用户写作指纹中的已有模式一致（需 ≥3 次出现） | "你的惯性——" |

## 紧迫度排序

```
crimson → amber → steel_blue → violet → slate_gray → pine_green
  (卡点)    (模式)    (推进)      (暗层)     (数据)      (惯性)
```

- 同一句子可触发多种颜色 → 取紧迫度最高者为主导信号
- 诊断输出按紧迫度排列信号（最紧迫的先说）
- 松绿仅在跨文本模式匹配时点亮（需写作指纹存在）

## 内部使用规则

1. **颜色名不向用户显示**：诊断输出中不说"这个句子是胭脂红"——颜色是内部分类工具，不是用户看到的标签
2. **动作句手势可选**：动作句可使用颜色对应的手势语言（"这里停下来——"/"这里有方向——"），但不过度标注
3. **信号驱动诊断**：先识别信号，再通过 X→Y→Z 框架组织输出——不是先有框架再找信号
4. **紧迫度决定篇幅**：crimson 卡点信号 → 展开分析；slate_gray 数据信号 → 一句话提及即可
5. **松绿是例外**：松绿是唯一跨文本的信号——其余 5 色全部来自当前文本

## 颜色→焦距映射

每种颜色信号通常由特定焦距维度触发：

| 颜色 | 主要触发焦距 | 说明 |
|------|-----------|------|
| crimson | 结构层 + 语义层 | 因果断裂是结构问题，逻辑跳跃是语义问题 |
| amber | 语言层 + 语义层 | 句法重复是语言层，意象反复是语义层 |
| steel_blue | 结构层 + 语用层 | 未展开的结构位置 + 读者期待的方向 |
| violet | 情感层 + 批判层 | 情感暗示 + 未说出的假设 |
| slate_gray | 数字层 → 各层 | 量化数据作为辅助注入其他焦距 |
| pine_green | 跨文本（各层） | 模式匹配跨越多层——句法/意象/逻辑/情感均可 |
