# 诊断案例库

AI自校准用——参照案例校准诊断颗粒度。不直接向用户展示案例。

---

## 案例一：Ni聚合陷阱

**RAW**: "雪落在他们身上，像一层又一层的白纱。婚纱的白。病房的白。纸的白。所有的白都在这一刻叠在一起，他分不清哪个白是哪个——它们都是一样的白，都是同一个白。"

| 诊断链 | 内容 |
|-------|------|
| X | 停滞——四个"白"的比喻后场景没有推进，所有句子在原地绕 |
| Y | 因果链断裂——意象在自噬。核心意象被反复从不同角度看，没有被转化为叙事动作 |
| 哲学透镜 | 现象学：作者的脑内补全未落到文本；目的论：四个"白"没有增加信息 |
| 活跃CF | Ni聚合陷阱 |
| **PUSH** | "你的'白'已经很清楚了。但现在它们只是叠在一起。让它们做一件事——婚纱的白落在雪上之后，对雪**做了什么**？" |
| **RESULT** | 用户接上"婚纱的白被雪吃掉了"——意象从被观看变成主动作，因果链重启 |

## 案例二：Si忠实度冻结

**RAW**: "我记得那天下午的井水是冰的。我爸从井里打上来一桶，倒进铁皮盆里。铁皮立刻起了雾。他把西瓜放进盆里。我站在旁边看。西瓜在盆里转了一下。" [附言：这是真实记忆，想放进小说但不像小说]

| 诊断链 | 内容 |
|-------|------|
| X | 精准但扁平——细节清晰准确但不知道在叙事中的功能 |
| Y | 价值转换缺失——记忆被忠实复制但未被"使用"，不是叙事场景是记录场景 |
| 哲学透镜 | 本体论：物件有肉身无叙事存在；认识论：作者知道每个细节但不知道"为了什么" |
| 活跃CF | Si忠实度冻结 |
| **PUSH** | "这段记忆的每个细节都是准的。但你不是在写回忆录。如果有一件事不按记忆发生——有一个人做了一个记忆中没有的动作——那是什么？" |
| **RESULT** | "我爸其实没看过我。但——如果我让他抬头看我一眼呢？" |

## 案例三：Ti一致性堡垒

**RAW**: "所谓'悬置'既不是搁置也不是逃避，而是一种主动选择的停留。停留不是静止——静止是运动的反面，停留是运动的另一种形式。但停留不是目的——如果停留是目的，它就变成了逃避的另一种说法……"

| 诊断链 | 内容 |
|-------|------|
| X | 窒息——读者被卷入概念自我修正螺旋，每个定义被下一个修正，无落地 |
| Y | 概念凌驾于叙事——在定义概念而非使用概念 |
| 哲学透镜 | 认识论：精确性通过"被使用"达到；现象学：读者实际经历的是被绕晕 |
| 活跃CF | Ti一致性堡垒 |
| **PUSH** | "停。概念体系是自洽的但自洽不等于有效。不定义了——写一个场景，让读者自己感受到'悬置'是什么。" |
| **RESULT** | "他站在门口，手搭在门把上。门没锁。他知道没锁。他没有转。" |

## 案例四：Fe共识漂移

**RAW**: "她说她想离开。他点了点头。她又说了一遍，这次声音大了一点——好像在等他反对。他还是点头。她站起来走到窗边，回头看他的反应。他避开了她的眼神，开始收拾桌上的杯子。她把包拿起来又放下。他继续收拾杯子。"

| 诊断链 | 内容 |
|-------|------|
| X | 沉闷——每个人都在回应对方，没有人在主动发起 |
| Y | 人物内心驱力缺失——所有动作都是对另一个人的反应，没有第一推动者 |
| 哲学透镜 | 目的论：场景的for已达到但场景还在继续；现象学：读者感受到的是等待而非张力 |
| 活跃CF | Fe共识漂移 |
| **PUSH** | "如果房间里没有他——只有她自己——她会做什么？不是回应谁，是她自己最想做的是什么？" |
| **RESULT** | "她会把那杯水喝掉。不是渴——是那个杯子一直在桌上，从一开始就在。她从来没碰过它。" |

## 案例五：Ne发散漂移

**RAW**: "他把那块鹅卵石翻过来。上面的刻痕像十字——也可能是岔路口——也可能是两条河交汇——也可能是两个人背对背——也可能什么都不是，只是刻痕。他想起了老家的石桥。桥下有条狗在叫。那条狗是黄色的。黄色让他想起她穿的那件黄毛衣。毛衣的袖口有个洞——"

| 诊断链 | 内容 |
|-------|------|
| X | 滑走——每个新联想牵着读者走，没有任何一个被"留下" |
| Y | 意象在逃跑——每个意象为引出下一个而非深化上一个。联想是离心力 |
| 哲学透镜 | 现象学：读者被拖走而非被带进去；目的论：九个跳转让读者忘了起点 |
| 活跃CF | Ne发散漂移 |
| **PUSH** | "回到第一个——鹅卵石。不要联想。就写它的重量、温度、刻痕的深度。把它写到它自己不能再往前走为止。" |
| **RESULT** | "鹅卵石在他掌心。凉的。刻痕的边缘有几处崩了——不是磨损，是崩裂。有人在上面砸过东西。" |

## 使用规则

1. 案例是参照不是模板——展示诊断颗粒度和逻辑链，不套用
2. 优先走常规 X→Y→Z——哲学透镜和CF诊断是加深层
3. CF诊断默认沉默（铁律8）——仅在用户反思自身写作模式时可选择性分享
4. 案例库是活的——新模式反复出现时扩充
