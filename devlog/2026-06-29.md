### Open Design 研究摘要

**仓库**：[nexu-io/open-design](https://github.com/nexu-io/open-design) · 72.5k ⭐ · v0.12.0 · TypeScript · 1.5GB

**Skill 协议**：
- 100% 兼容 Claude Code `SKILL.md` 格式（YAML frontmatter: `name` + `description` + `triggers`）
- OD 扩展 `od:` 块全部可选：`mode`（prototype|deck|template|design-system|image|video|audio|utility）、`preview`、`inputs`、`parameters`、`craft`
- 零字段 → 自动推断默认值，现有 Claude Code skill 零修改运行

**分类体系**（重构后）：
- `skills/` → 功能性技能（~6 个：brainstorming、design-brief、brand-extract 等）
- `design-templates/` → 设计模板（~100+ 个：prototype、deck、image、video 等）

**text-lens 适配方案**：
- text-lens 属 `od.mode: utility`（功能性文本分析工具）
- **P0 必须**：添加 YAML frontmatter（`name: text-lens` + `description` + 中文 `triggers`）
- **P1 推荐**：`od.mode: utility` + `zh_name`/`zh_description` 本地化
- **发布路径**：保持独立 GitHub 仓库，OD 用户 `od skill add https://github.com/dcctc5kf7z-byte/text-lens` 一键安装
- **可选 PR**：向 OD 提交轻量 curated stub（参考 `brainstorming` 的做法）

**安装**：
- 下载页：https://github.com/nexu-io/open-design/releases/latest
- Windows：`open-design-0.12.0-win-x64-setup.exe` (277MB)
- 安装后 `od mcp install claude` 即可在 Claude Code 中使用
